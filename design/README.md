# YBZ 设计参考

本目录保存用户提供的五份原始设计文件，原文不改写。规范与 HTML 中的早期命名、示例数字及产品状态不代表当前功能。

以 2026-10-10 用户最终指令为实施准则：中文主名“愚笨者”，英文主名“YBZ”；三要素固定为“思维、决策、创造性”；品牌主张“技能交给 AI，判断留给自己。”。五 Tab 顺序为工作台、消息、钱包、发现、我的，工作台默认落地。

最新指令覆盖旧稿差异：仅 Hero 背景与主按钮使用指定渐变，头像及普通卡片不用装饰渐变；中文标题字距 +0.5px，英文 -0.7px；图标描边 2.2px。界面使用实际数据或明确的空状态，不复制设计稿的示例积分、任务进度、云机连接和人数。

固定积分说明中的“不可提现”是该原文的必要组成部分，其他页面不出现提现入口或可兑现暗示。设计稿“手续费 $0.01”是示例，实际链上转账应如实显示真实费用。
