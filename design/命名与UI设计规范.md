## 零、品牌精神内核（一切命名的起点）

**AI 时代，人人都是愚笨的。**

写代码、翻译、记账、检索、总结——任何单项技能都比不过 AI。承认这一点不是自嘲，是**清醒**。

人真正厉害的，是 AI 给不了的三样：

| 能力 | 说明 |
|---|---|
| **思维** | 知道要什么、为什么；能判断什么值得做 |
| **决策** | 环境变了能立刻定方向、改路线 —— 判断和取舍只能人来做 |
| **创造性** | 能把两个不相干的东西连成新东西 |

**品牌主张：技能交给 AI，判断留给自己。**

> 这条内核直接决定了命名策略：**不要叫「我笨」**（那只是自嘲），
> 要叫**「我不如 AI，但我知道该往哪走」**（那是底气和方向）。

### 1.2 命名策略转向

英文里常见形容词（wise / humble / smart / instinct / keen …）**几乎被占满**。所以改走两条路：

| 方向 | 含义 | 备注 |
|---|---|---|
| **A ·「人在 AI 之上」** | 不描述「笨」，描述「人比 AI 多出来的那部分」——思维、判断、创造 | 最贴内核，英文最不易撞车 |
| **B ·「还在学」** | 强调「一直在适应、一直在变」的动态 | 有生长感，适合长期品牌 |

**中文主名：愚笨者**（保留，不译）
中国语境里「愚笨者」= 自嘲 + 清醒，有「愚者千虑，必有一得」的底子。中国市场直接用中文名，识别度最高。

**英文主名：待定向查证后确定，不做直译。**

> ⚠️ 我下一步可以按 A / B 两个方向各出 3–5 个候选词，逐个跑域名 + 商标 + 商店查重，
> 给你一张「可用 / 有风险 / 已占用」的对比表。这是唯一不会再翻车的做法。

## 二、UI 设计系统

### 2.1 设计原则（国际风格）

1. **深色 Hero + 亮色强调** —— 每个主界面顶部一块深色区承载核心信息，下方白底卡片区做内容
2. **大圆角 + 大留白** —— 卡片圆角 14px，Hero 底部圆角 28px，屏幕左右内边距 24px
3. **不堆装饰性渐变** —— 渐变只用两处：Hero 底色、主按钮
4. **图标线性化** —— 1.8–2.2px 描边，不加填充，24×24 网格
5. **数字用等宽** —— 余额、积分、金额一律 `font-variant-numeric: tabular-nums`
6. **每个界面 1 个主行动** —— 不出现两个同权重按钮

### 2.2 设计令牌（直接复制进代码）

```css
:root{
  /* 基础墨色 */
  --ink:#1B1B1F;
  --ink-2:#2D2A3E;

  /* 品牌强调 */
  --accent:#6C5CE7;      /* 主色：AI / 主按钮 */
  --accent-2:#A29BFE;    /* 主色浅阶：渐变尾 */

  /* 语义色 */
  --teal:#00B8A9;
  --amber:#FFB020;
  --green:#00C48C;
  --red:#FF3B30;

  /* 中性阶 */
  --grey-1:#F7F7F9;
  --grey-2:#F0F0F5;
  --grey-3:#E8E8EE;

  /* 文字阶 */
  --text:#1A1A1A;
  --text-2:#666;
  --text-3:#999;

  /* 圆角 */
  --radius-s:8px;
  --radius-m:14px;
  --radius-l:20px;
  --radius-xl:28px;
}
```

**两处固定渐变**

```css
/* Hero 底色 */
background:linear-gradient(140deg,#1B1B1F 0%,#2D2A3E 100%);

/* 主按钮 */
background:linear-gradient(90deg,#6C5CE7,#A29BFE);
box-shadow:0 8px 22px rgba(108,92,231,.36);
```

### 2.3 字体阶梯

| 用途 | 英文版 | 中文版 | 字重 |
|---|---|---|---|
| 页面标题 | 29px / −0.7px | 29px / +0.5px | 800 |
| Hero 主标题 | 27px / −0.5px | 27px / +0.5px | 800 |
| 大数字（余额 / 积分） | 31–34px / −1.0px | 同 | 800 |
| 卡片标题 | 14px | 14px | 650 |
| 正文 / 副标题 | 12–13px | 12–13px | 400 |
| 分组标题 | 11px / +0.9px UPPERCASE | 12.5px / +0.5px 中文 | 700 |

**字体族**
- 英文：`-apple-system, BlinkMacSystemFont, "Segoe UI", "Inter", system-ui, sans-serif`
- 中文：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`

> 中文字距要**加**而不是减（英文做法在中文上会显得挤）；中文分组标题不做 UPPERCASE。

### 2.4 间距系统

`4 / 8 / 10 / 12 / 14 / 16 / 20 / 24 / 32`

- 屏幕左右内边距：**24px**
- 卡片之间：**10px**
- 分组之间：**26px**
- 底部给 tabbar 留白：**88px**

### 2.5 五个 Tab 的职责

| 顺序 | 英文 | 中文 | 职责 | 主行动 |
|---|---|---|---|---|
| 1 | Workspace | **工作台** | AI 工作台（**第一主任务**） | 新建任务 |
| 2 | Messages | **消息** | 聊天 + 红包 + 熟人社交 | 发消息 |
| 3 | Wallet | **钱包** | 自托管钱包（只读 + 收发） | 转账 |
| 4 | Discover | **发现** | Agent / Prompt / 模板 | 试用 |
| 5 | Me | **我的** | 身份展示 + 账户设置 | — |

> ⚠️ **工作台必须放第一位。** 原需求文档是「消息」第一，现在要调整——AI 工作台是主任务。
> 这条同时要改 `需求文档改造指令_V0.1到V0.2.md` 里的入口顺序。

### 2.6 文案红线（已在两份设计稿中落实）

| 位置 | 必须出现的原文（中文版） |
|---|---|
| 工作台积分卡下方 | 积分不可转让、不可提现，仅可用于消耗站内服务。 |
| 钱包卡下方 | 密钥保存在你自己的设备上，平台不托管、不接触你的资金。 |
| 转账记录 | 明示「手续费 $0.01」（费用透明，不藏） |

英文版对应：
- `Credits are non-transferable and can only be used for in-app services.`
- `Your keys stay on this device. ___ never holds your funds.`

**界面中禁止出现：**
- ❌ 余额 / 平台余额（平台余额概念已删除）
- ❌ 提现（只有转账 / 收款，且是链上自托管）
- ❌ 积分转让 —— 积分只能消费
- ❌ 任何「邀请好友得奖励」「分享得积分」文案（踩苹果 3.1.5(v) 红线）

### 2.7 Hero 里的内核文案

工作台 Hero 区放一句品牌主张，让用户一进 App 就懂这是什么产品：

- 中文：**技能交给 AI，判断留给自己。**
- 英文候选：`Let AI do the doing. You do the deciding.`

（这句已放进中文设计稿的工作台 Hero 里，右侧头像用「愚」字）
