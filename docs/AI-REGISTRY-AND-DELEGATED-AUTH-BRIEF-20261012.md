## 一句话

要把「所有 AI」接进来，**核心是建一个「AI 注册表」**——电脑自己扫描装了哪些 AI，手机照着生成聊天入口。

| | 现在 | 你要的 |

**⚠️ 关键：不是「加个下拉框」那么简单。** 「Codex」这个词被写死在 **7 个地方**，其中一个还是**硬校验**——别的 AI 上报直接被服务器拒绝。

## 要做四件事

### ① 电脑端：AI 注册表（核心）

电脑扫描本机，输出：

```
Codex   ✅ 装了，已登录
WorkB   ✅ 装了，已登录
Claude  ❌ 没装
Ollama  ❌ 没装
```

**扫描纪律**（很重要）：
- 每条独立超时，**一条卡住不能拖垮全部**
- **绝不扫描全盘找 exe**（慢且吓人）
- **绝不读 AI 的密码/配置**，只看「在不在」
- 检测不出来就老实说「没装」，**不猜**

### ② 服务器：从「写死」改成「透传」

把 7 处硬编码拆掉。**仍然只转达，不存对话内容。**

### ③ 手机端：动态生成 AI 板块

设备详情页里长出 AI 入口：

```
┌─ 我的电脑 ──────────────┐
│ AI 板块                  │
│ ┌────────┐ ┌────────┐  │
│ │ Codex  │ │ WorkB  │  │ ← 装了的
│ │ 已登录 │ │ 已登录 │  │
│ └────────┘ └────────┘  │
│ ┌────────┐              │
│ │ Claude │              │ ← 没装的
│ │ 未安装 │              │
│ └────────┘              │
└─────────────────────────┘
```

**⚠️ 需要你拍板一个小点**：「没安装的」是**不显示**，还是**显示但标灰**？

- 我建议**标灰 + 说明「请在电脑安装」**——因为你说「要备注 codex workB claude 等等」，听起来你是想要**看得见的清单**，能看到「还差什么」
- **但两种都做成开关**，你随时能切

### ④ 帮用户登录 = ⚠️ 这条要拆成两档

你说「帮助用户点击授权…帮助用户登陆账户」。**这件事有风险，我必须跟你说清楚。**

| 档 | 做什么 | 风险 |
|---|---|---|
| **🟢 D1 安全档** | 只**提醒**：「这台电脑的 Codex 需要登录，请在电脑上完成」 | **零风险** |
| **🟡 D2 代操作档** | 电脑帮你**自动打开登录页、填密码、点授权** | 🔴 见下 |

**⚠️ D2 的三个真实风险**：

1. **可能违反 AI 服务条款** —— 大多数 AI 服务**明确禁止**自动化登录
2. **后果可能是你的 AI 账号被封** —— 这是真金白银的损失
3. **凭据经手** —— 帮登录就意味着代码碰得到密码

**现在的代码是故意不做这件事的**，`capabilities.mjs:30` 原文写着：

> 「请从官方来源安装并**由本人登录**」

**➡️ 我的建议：先只做 D1（提醒），把 D2 留着。**
因为 D1 已经能解决 90% 的体验问题（用户不用猜「为什么跑不了」），而且零风险。

**如果你还是要 D2**，那必须满足四条硬约束：确认弹窗不可跳过 / 凭据绝不落盘 / 无人看屏时禁止 / 默认关闭能一键关停。
