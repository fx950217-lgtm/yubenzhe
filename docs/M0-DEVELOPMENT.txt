愚笨者 requirements v0.1 本地开发基线（2026-10-10）
授权：本轮用户明确选择“先完成本地测试版”。现网 0.13.0 不更新；不购买服务、不发送真实邮件、不接主网资金。

需求映射与阶段：
已有：消息、好友、群组、头像、举报/拉黑、朋友圈、测试网本地加密钱包、基础云模型文字任务。
M0 本轮：邮箱模拟登录 + 标准通行密钥接口；UUID 独立模拟复式账本、绑定/解除与保护状态、红包；真实持久化赏金论坛/服务商目录/自愿榜单/在线等级；平台承担预算的本地文件工作台。
M1A 待外部配置：真实邮箱、云桌面服务商、两种真实模型、运营主体/地区；完成实体设备及真实远程桌面验收。
M1B 待明确授权及审计：真实托管签名、主网稳定币登记、真实充值提现、链上发币与资金核对。

模块结构：
消费者五栏：消息 / 通讯录 / AI 工作台 / 发现 / 我。发现保留朋友圈、赏金、服务商、排行榜、发币；未接真实服务必须显示具体状态。
后端沿用模块化单体，social-state 保存账户及新模块；原 ai-state 文本任务继续独立。管理接口仍受独立管理认证。新增消费者模块各自重新校验会话、UUID 所有权、幂等键与状态版本。
新增迁移：008-account-access（邮箱/通行密钥/恢复/保护）；009-platform-assets（登记、绑定、复式账本、订单、红包）；010-community（赏金/服务商/等级/认证/榜单）；011-workbench（文件任务/预算/用量/审批/成果）；012-workbench-experience（自然语言目标/版本化计划/指令/到期提醒）；013-social-experience（自愿发现/群角色与审批/禁言/引用）。迁移只追加，不改已发布迁移。

主要数据关系：
Account UUID -> Credential/Session/RecoveryCase；公开 ID 是可变属性。
Account UUID -> LedgerAccount -> JournalEntry/Line -> Deposit/Withdrawal/Gift/Claim；WalletBinding 是可解除的关联，绝不作为账本所有者。
Account UUID -> WorkbenchWorkspace -> Task -> Input/Output/Usage/Invoice；预算单位为整数微美元，模拟试用由平台承担，绝不从用户钱包扣钱。
Account UUID -> Bounty/Application/Delivery/Review、Provider、Activity、Certification、RankingPreference。

状态与接口：
/api/social/access/*：邮箱请求/核验、通行密钥注册/登录/验证、资金激活与恢复。邮箱码不授予资金权限。
/api/social/assets/*、gifts/*：账本、钱包绑定挑战/提交、解除、充值记录、提现报价/订单、红包创建/领取/退款；真实外部执行由可信适配器完成。
/api/social/community/*：服务商、赏金、评论/申请/交付、榜单、活动心跳。
/api/social/workbench/*：能力、文件上传、估价、确认、任务列表/详情、暂停/恢复/取消/接管、成果下载。
钱包解除：服务端解除并取消确定未广播单 -> 本地清理 -> 清理确认；未知广播继续核对。
工作台：draft/awaiting-confirmation -> queued -> running -> succeeded/failed/cancelled；允许 paused/awaiting-user/budget-paused，恢复使用同一任务和工作区。预算 quoted/reserved/settling/settled，重复用量不重复计费。外部桌面未配置时返回 unavailable，不能用假屏幕代替。

实施与验收：
1 先模块实现及迁移、边界单测；2 统一接线和五栏；3 浏览器端邮箱 -> 好友 -> 模拟红包 -> 文件预算任务 -> 下载闭环；4 失败与重试、权限隔离、钱包解除保留资产、并发退款验证；5 完整回归与交接矩阵。
AC01–31 的最终结果记录在 M0-ACCEPTANCE.txt；未接外部服务或未实际验证项目必须明确标记，不用测试通过冒充上线。
