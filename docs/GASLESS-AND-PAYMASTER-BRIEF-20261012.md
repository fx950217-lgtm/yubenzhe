# Gas 代付：一页看懂

日期：2026-10-12
你的问题：**「钱包+社交的产品 有没有合约的方式，解决 gas 费的」**

---

## 一句话回答

**能。用 ERC-4337（账户抽象）+ Paymaster。**

但先弄明白一件事：**gas 没有被消灭，只是从「用户掏钱」变成「你掏钱」。**

「免 gas」是营销话术，技术上的真名是 **「平台代付 gas」**。

---

## 三个关键判断

### ✅ 1. 跟「平台零收费」不冲突

| | 管的是 | 结论 |
|---|---|---|
| 零收费方针 | **收入**（你不收用户钱） | |
| 代付 gas | **支出**（你替用户付给链） | |

**你不收钱 ≠ 你不能花钱。** 这两件事不打架。

而且零收费还帮你挡了 Apple 3.1.1 —— 平台没东西要买要解锁，这条天然规避。

### ⚠️ 2. 但这是每天在烧的现金

| 链 | 一次领取的 gas |
|---|---|
| **BSC** | **约 $0.01–0.05** ← 最便宜 |
| Polygon | 约 $0.01–0.10 |
| Arbitrum | 约 $0.05–0.30 |
| **以太坊主网** | **约 $0.5–5** ← 红包千万别走主网 |

**举例**：日活 1000 人、每人每天领 1 次，全走 BSC → **约 $900/月**。

这个数字**随用户量线性上涨**，所以必须先定月度预算上限。

### ⚠️ 3. 要换钱包地址（这是最贵的代价）

ERC-4337 的钱包是**智能合约钱包**，**地址跟现在的不是同一个**。

- 老用户有资产的要迁移
- **但你现在是测试网（tBNB 没价值）→ 现在改，代价最低**

**这是一次性的架构窗口。等主网上线有真钱了再改就贵了。**

## ⚠️ 最大的坑：会被刷爆

代付的 paymaster 是**攻击者的明确目标**。必须做四件事：

1. **白名单**（只赞助特定合约/方法）
2. **限速**（按用户/按小时）
3. **单笔 + 每日上限**
4. **预算耗尽自动降级**（提示用户自付，不要崩）

**政策要当「风险限额」写，不是当「功能开关」写。**

---

## 🔴 红线（绝对不能做）

- ❌ 把代付做成**可充值/可购买/可转赠的「gas 额度」** → 踩 Apple 3.1.1
- ❌ 做**「邀请返利送 gas」「完成任务送 gas」** → 踩 Apple 3.1.5(v)
- ❌ 用平台私钥直接代发（= 托管）→ 合规爆炸

**记住那句：代付是「你替用户付账」，绝不能变成「你给用户发钱」。**
