# 工作台 UI 重构 · 对标研究与设计方案

> 目标：把「愚笨者」AI 工作台首页从「功能目录」改成「客户上手就能用」。
> 对标 10 个产品实际查证（2026-10-11）。

---

## 二、共性规律（这是最有价值的部分）

### 规律 1：面向普通人的产品，首屏根本不写大标题

- **工具型**（Perplexity / Kimi / Jan / Poe / 豆包 / 千问）→ **没有营销标题**，输入框就是主角。占位符 **≤15 字**。
- **官网型**（AnythingLLM / LM Studio / Ollama）→ 标题 **6–11 词**，副标题 **1 句 15–30 词**，**全部不超过两行**，且核心卖点永远只有一句（隐私 / 本地 / 自由）。

> **对照现状**：现在 Hero 区有 7 行文字（标题+副标题+说明+待接入提示+名言+三个词）。**超了 3 倍以上。**

### 规律 2：主按钮最多 1 个

**没有任何产品首屏有超过 2 个大按钮。** 绝大多数只有 1 个。

> **对照现状**：首页有 9 个可点入口平铺。**严重超标。**

### 规律 3：面向非技术用户，必须「按场景」而不是「按功能」

- 按场景（Perplexity / 豆包 / Kimi）→ 认知负担低，**适合不懂技术的人**
- 按功能平铺（Cherry / 千问 / Open WebUI）→ 认知负担高，**适合开发者**

调研结论原文：**「面向不懂技术的人，应偏向场景/意图入口」**

> **对照现状**：现在是「我的设备 / 云端电脑 / 模型与工具 / 文件小工具 / 积分 / 近期动态」——**纯按功能平铺，正是应该避免的那种。**

### 规律 4：新用户引导 = 二选一 或 3–4 步；问卷极少见

- 高频手法一：**二选一卡片**（Chatbox「我是新手 / 跳过」）
- 高频手法二：**3–4 步图文**（AnythingLLM 4 步）
- **「跳过（Skip）」几乎是标配**
- 降低门槛最强的一招：**「或让我们替你选」**（AnythingLLM 自动按硬件推荐模型）

> **对照现状**：已有三步引导（在设备页里），但没有「跳过」，也没有「让我替你选」。

### 规律 5：一级导航不超过 6 项，主流是 3–5 项

Perplexity 3 / Jan 3 / 豆包 3 / 千问 4 / Poe 4–5 / Cherry 6。**没有超过 6 的。**

### 规律 6：空白状态（empty state）用「可点示例」，不写说明书

主流做法：**问候语 + 4–6 个可点示例卡**。调研原文：**「几乎不用大段说明文字，用可点击的示例代替教学。」**

> **对照现状**：首页有 4 句自我说明文字（「我们不提供 AI 本身…」「当前需你按说明安装…」），是**典型反面教材**。

## 三、给「愚笨者」的可落地数值

| 项目 | 对标建议 | 现状 | 要改成 |
|---|---|---|---|
| 首屏文字行数 | ≤2 行 | 7 行 | **2 行** |
| 主按钮 | 1 个 | 1 个（但被淹没） | **1 个，做大** |
| 首屏入口 | 3–5 个场景卡 | 9 个 | **3 个** |
| 一级导航 | ≤6 项 | 2 项（工作/聊天） | **保持 2 项，但移到次要位置** |
| 说明文字 | 收进「关于」 | 4 句散落 | **全部收进折叠** |
| 空白状态 | 可点示例 | 大段说明 | **改成可点卡片** |

## 四、最终方案：三条路（对应你的两条用户路径）

### 首屏结构（从上到下，就 4 块）

```
┌────────────────────────────────┐
│  把电脑变成 AI 工作站            │  ← 主标题（10 字）
│  装 AI · 配环境 · 连手机         │  ← 副标题（1 行）
├────────────────────────────────┤
│  ①  我要连接自己的电脑       →  │  ← 主入口（高亮）
│      先装手机 App，再装连接器    │
├────────────────────────────────┤
│  ②  我要装 AI                →  │
│      免费 / 按量 / 有额度 / 最好 │
├────────────────────────────────┤
│  ③  我没有电脑               →  │
│      云电脑 · 待接入            │
├────────────────────────────────┤
│  积分 1,000 · 我的任务 · 聊天    │  ← 一行小字
└────────────────────────────────┘
```

### 三条路各自点进去

**路①：我要连接自己的电脑**
- 已连过 → 直接显示设备状态卡（在线/离线）+「打开」按钮
- 没连过 → 三步引导（① 手机装 App ② 电脑装连接器 ③ 装 AI）
- **加一个「跳过，先看看」**（对标 Chatbox）

**路②：我要装 AI**
- 四档卡片（对标 AnythingLLM 的「或让我们替你选」）
- 免费 Ollama / 按量 DeepSeek / 有额度 Codex CLI / 最好 ChatGPT Plus
- **加一句「不知道选哪个？用免费的就行」**（替客户做决定）

**路③：我没有电脑**
- 云电脑，标「待接入」
- **不留假按钮**（现状那个 disabled 按钮是对的，保留）

### 收起来的东西（不是删掉）

全部用 `<template data-retired-home-entries>` 保留，代码一字不删：
- 「工作/聊天」切换 → 移到底部小字
- 积分卡 → 缩成一行
- 文件小工具 → 并进「我的任务」
- 4 句说明 → 收进「关于」折叠

---

## 五、文案纪律（沿用并收紧）

1. 主标题 **≤10 字**（现在 11 字：「把你的电脑变成 AI 工作站」，保留但精简）
2. 副标题 **1 行，≤20 字**
3. 「待接入」就是「待接入」，**不写「即将上线」**
4. **不写价格数字**，只写「免费 / 按量付费 / 有免费额度 / 按服务商标准」
5. **不做假按钮** —— 功能没做就不给能点的按钮
6. 说明文字**一律收进折叠**，首屏只留行动
