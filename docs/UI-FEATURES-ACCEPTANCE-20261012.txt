五、关键行为与三个闭环

AI＋社交：本轮实现并验证本人消息入口、群主AI名单/备注、群头像私聊、群决策与回复回群。设备操作权限仍只属于主人；群友只能看到已授权分享的内容，不能操作或私聊别人的设备。
AI＋区块链钱包：原有任务成果、用户验收、钱包本人签名、未知付款只查原交易逻辑保留。消费者钱包与本地EVM联测通过。本轮未新增真实模型＋公网测试网端到端交易。
社交＋区块链：原有群任务、付款回执与权限校验保留，task-payment-verifier及全部合约文件未改变。本轮没有发公网测试币或主网交易。

决策是严格结构化协议，不把普通AI建议猜成授权。收到决策后当前执行段先停止；人点选后创建一个关联原工作目录的新执行段，不声称恢复同一个进程。
30分钟无人选择挂起；RAM丢失/重启/决策正文失效时挂起，不猜选项、不自动重跑。超时自动测试使用可控时钟。
数据库只保存决策摘要、选项ID、批准者、时间、版本与续段关系；问题、选项正文、prompt、回复及文件字节不进入AI业务表。普通社交消息沿用原有持久化规则。
相同请求幂等；结果未知保留原requestId，允许用户核对或手动重试原选择，不自动批准。群任务回到群讨论页选择并保持执行心跳，保留P7离页停止保护。
通知只发送完成、待决策、失败；群续段不单独重复发完成。发前重核账号、设备、群主版本与名单授权。通知内容仅固定类型与事件ID，不含任务/对话/决策正文。发送确认未知可用同事件重试，浏览器tag去重；不承诺网络层严格只送达一次。
