## 一、两条路径的完整拆解

### 路径 A：有电脑的用户

**用户视角只有 4 步**（这是目标，越少越好）：

```
① 手机装 App        →  扫码 / 应用商店
② 电脑装连接器      →  在手机上生成一个"安装链接"，电脑上点开就装
③ 选 AI（我们推荐）  →  手机上看一个推荐列表，点"装这个"
④ 自动关联          →  什么都不用做，聊天栏自动出现
```

**关键技术点**：

| 步骤 | 怎么实现 | 难点 |
|---|---|---|
| ② 电脑装连接器 | **手机上生成配对链接 → 电脑打开 → 自动下载并运行** | 需要把 `.exe` 做成**免安装单文件**（现在是 `.cmd` + Node） |
| ③ 一键装 AI | 连接器里内置包管理器，**我们代跑安装命令** | 见第二部分 |
| ④ 自动关联 | **已经有了** —— `devices/pair` + `enroll` 已实现 | 无 |

**你现在已有的**（`device-bridge/`）：
- ✅ 设备配对（一次性配对码，10 分钟过期）
- ✅ 电脑主动外连（零入站端口）
- ✅ 屏幕 + 鼠标 + 键盘 + 中文粘贴
- ✅ 一键启停 `.cmd`

**你缺的**：
- ❌ 电脑端不是"一键安装"（现在是解压 + 跑 cmd）
- ❌ 没有 AI 安装包列表
- ❌ 没有"帮客户装 AI"的能力

### 路径 B：没电脑的用户

```
① 手机装 App        →  同路径 A
② 选套餐付费        →  基础办公 / 图形开发
③ 我们开通云机      →  后台自动开（已有骨架）
④ 云机一键装环境    →  谷歌浏览器 + 常用软件 + AI
⑤ 自动连到聊天框    →  和路径 A 的 ④ 完全一样
```

**你现在已有的**：
- ✅ 云电脑后端骨架（3 张表 + 幂等开通 + 凭据加密 + 改密 + 注销）
- ✅ 云端 AI 聊天（已接 qwen3:0.6b，公网可用）
- ✅ 远控协议（云机可以复用同一套）

**你缺的**：
- ❌ 真实云服务商（AWS WorkSpaces 没接）
- ❌ 云机的"一键装环境"脚本
- ❌ 付费开通流程（支付明确暂停中）

### ⭐ 一个关键洞察：两条路径的**终点是同一个**

```
路径 A：我的电脑  ┐
                  ├→  统一的聊天框 + 统一的远控
路径 B：我们的云机 ┘
```

**这意味着**：路径 A 的技术积累**直接就是路径 B 的基础**。

> **重要建议**：**先做路径 A**（因为已跑通一半），路径 B 等路径 A 验证后再做。
> 路径 B 是重资产（要垫钱买机器），路径 A 零边际成本。

## 二、⭐ 最硬的骨头：「一键安装 AI」

这一节是整份文档最重要的部分。**你的构想里，"一键装 AI" 是整个产品的灵魂**，但它有三个真实的坑。

### 坑 1：AI 工具大部分**不能真正静默安装**

| 工具 | 能否一键静默装 | 说明 |
|---|---|---|
| **Node.js / Python** | ✅ 可以 | 有官方静默安装参数 |
| **Ollama**（本地模型） | ✅ **可以** | 官方提供一键安装脚本，最适合我们 |
| **ChatGPT 桌面版** | ⚠️ 半自动 | 可以下载 `.exe` 并启动，但首次登录要用户自己点 |
| **Codex CLI** | ✅ 可以 | 一条命令 `npm i -g` 就行 |
| **Claude Code** | ✅ 可以 | 同上 |
| **各类国产 AI** | ⚠️ 看情况 | 有的要手机验证，没法代装 |
| **需要登录的 AI** | ❌ **做不到全自动** | 账号密码只能用户自己填 |

> **人话**：**"装软件"能一键，"登录账号"不能。**
> 任何要登录的东西，最后一步必须用户自己动手。

### 坑 2：用户电脑上的**安全软件会拦**

这是最现实的障碍：
- Windows Defender 会拦"未知来源的程序"
- 国内电脑基本都装 360 / 腾讯电脑管家 —— 它们**很可能直接拦截我们的安装脚本**
- 用户看到弹窗"是否允许修改" → **大部分人会点"否"**

**应对方案**（必须做，否则功能废掉）：
1. **申请 Windows 代码签名证书**（约 $100–300/年）—— 让安装包显示"已验证的发布者"
2. **安装前给出明确的图文引导**（截图标注版，告诉用户"看到这个弹窗点'允许'"）
3. **尽量用官方安装包**（而不是我们自己打包的 exe）—— 官方包的信誉更好，拦截率更低

### 坑 3：**"帮客户装软件"有法律责任**

如果我们在客户电脑上装东西，出了事（比如装了个带广告的软件），**责任在我们**。

**规避方法**：
- **只装官方来源的软件**（附官方下载链接，可追溯）
- **安装前让用户明确勾选**"我同意安装以下软件"（留痕）
- **绝不装来源不明的软件**（哪怕是"免费好用"的）
- 所有安装动作**记录日志**（谁、什么时候、装了什么）

## 三、AI 推荐清单（这是你要的"咨询客户装哪个"）

你说要按「免费 / 功能可以 / 少量花费 / 贵但效果好」分档。**这就是那个清单：**

| 档位 | 工具 | 价格 | 适合谁 | 能否一键装 |
|---|---|---|---|---|
| **① 完全免费** | **Ollama + 小模型** | 免费 | 只想试试、不想花钱、不怕慢 | ✅ 全自动 |
| **① 完全免费** | 浏览器版 AI（网页） | 免费 | 临时用、不装东西 | ✅ 只是打开网页 |
| **② 少量花费** | **DeepSeek** | 极便宜（几块钱能用很久） | **大多数人 —— 这是我最推荐的** | ⚠️ 装客户端容易，但**要用户自己注册拿 Key** |
| **② 少量花费** | ChatGPT 免费版 | 免费 / $20 月付 | 已经在用的人 | ⚠️ 半自动 |
| **③ 功能可以** | **Codex CLI** | 含在订阅里 | 想让 AI **帮他干活**（不只是聊天） | ✅ 命令行一键装 |
| **③ 功能可以** | **Claude Code** | 含在订阅里 | 同上，体验更好 | ✅ 命令行一键装 |
| **④ 贵但最好** | ChatGPT Plus / Claude Pro | $20/月 | 专业用户、重度使用 | ⚠️ 要用户自己付费 |

### ⭐ 我的推荐逻辑（把这个做成 App 里的"咨询"）

```
打开连接器 → 回答 3 个问题：
  1. 你主要想用它做什么？（聊天 / 写东西 / 让 AI 帮你操作电脑）
  2. 你愿意花钱吗？（不花 / 每月几十块 / 不设限）
  3. 你的电脑配置如何？（自动检测，不用用户答）

→ 推荐结果：
  不花钱 + 只是聊天        →  Ollama（全自动装好）
  花小钱 + 要真正好用      →  DeepSeek（引导注册，几步搞定）
  要 AI 帮我干活          →  Codex / Claude Code（一键装 + 引导登录）
  不差钱 + 要最好          →  ChatGPT Plus / Claude Pro（引导付费）
```

**这个"问 3 个问题给推荐"的功能，本身就是你产品最有价值的部分。**
因为它把"我要装哪个 AI"这个让普通人崩溃的问题，变成了一个选择题。

## 五、⚠️ 三个必须提前知道的现实

### 现实 1：云机是重资产，起步阶段会亏

- AWS 的目录服务固定 **$36/月**，1 个人用也是 $36，100 个人用也是 $36
- 单用户成本：10 人时约 $20/月，1000 人时才降到 $4.40/月
- **所以用户少的时候，每卖一台亏一台**

**建议**：路径 B **等路径 A 有真实用户后再做**。现在做等于烧钱验证。

### 现实 2：收钱这件事要律师

你说"客户付费开通云机"。这一步涉及：
- 你代收客户的钱，再付给 AWS → 这是**转售**，可能有电信/云服务资质要求
- 如果让客户直接付给 AWS → 合规更简单，但体验差（要客户自己开 AWS 账号）

**建议**：**先用 AWS 的渠道/代理体系**（VDI 合作伙伴价 $16.80/桌面/月），它本身就是为转售设计的，链条清晰。
**定价前必须拿一次律师意见。**

### 现实 3：「一键安装」的期望值要管理好

很多用户以为"一键"= 什么都不用做。但实际上：
- 装软件 → 能一键
- **登录账号 → 必须用户自己**

**建议**：在界面上就诚实说明。
> 「我们会帮你装好软件。但登录账号要你自己来 —— 因为**那是你的账号，我们不该碰**。」

**这句话反而是加分项** —— 它和你的钱包理念一致（自托管、不碰用户的东西）。
