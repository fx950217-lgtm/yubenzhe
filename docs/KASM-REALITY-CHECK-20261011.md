## 一、先回答「服务器在哪里」

**这是 Kasm 最特殊的地方 —— 它没有「服务器在哪里」这个问题，因为服务器由你决定。**

### 1.1 四种部署方式

| 方式 | 服务器在哪 | 谁能做 |
|---|---|---|
| **自托管（Self-hosted）** | **你自己租的服务器，你说了算** | 任何人 ✅ |
| 私有云 / 混合云 | 你的 VPC / 你的机房 | 你 |
| 气隙（Air-gapped） | 完全断网的机房 | 你（政府/军工级需求） |
| **Kasm 官方云**（Cloud Personal） | Kasm 自己的机房 | 付款即可 |

**这就是它跟 AWS / 微软的根本差别**：

- AWS WorkSpaces → 机器在**亚马逊**的机房，你只是租户
- Kasm 自托管 → 机器在**你自己**的 VPS 上，Kasm 只是软件

### 1.2 所以你「服务器在哪里」完全由你选

**关键建议**：**机房要尽量靠近你的最终用户**，因为云桌面是实时流媒体，延迟直接决定体验好坏。

| 你的客户在哪 | 推荐机房位置 |
|---|---|
| 越南 / 东南亚 | **新加坡、越南本地**（你已经有新加坡机器了） |
| 中国大陆 | 中国香港、新加坡 |
| 欧美 | 美国西部、法兰克福 |

**⚠️ 你现在那台新加坡 VPS 跑不动 Kasm。** 见下面第六节。

### 1.3 Kasm 官方云（如果你买这个）

- **Cloud Browser**：$10/月，100 小时，2GB 内存
- **Cloud Desktop**：$20/月，200 小时，4GB 内存
- **Cloud OSINT**：$40/月，300 小时

**机房位置官方没公开**（我没查到具体区域列表）。**Kasm 公司总部在弗吉尼亚州 McLean**，但这不等于机房位置。

### 1.4 ⚠️ 如果是自托管，有一个「没服务器」的坑

Kasm 的**镜像库（Registry）**和**授权服务器**在它自己那边。所以即使自托管：

- 拉取 workspace 镜像 → 要连 Kasm 的镜像库
- 气隙部署 → 需要额外做离线镜像同步

**除此之外，你的数据、你的客户桌面，全都在你自己的机器上。** 对客户交代「数据在你自己的机器上」这句话是成立的。

## 三、逐条说清楚

### 3.1 ✅ 第 1 条：浏览器访问 —— 这条 Kasm 是真的强

- 客户打开一个网址 → 输账号密码 → 看到桌面
- **不用装客户端、不用 VPN、不用装插件**
- 手机浏览器也能用（响应式 Web UI）
- 有 Windows / macOS / Linux / 桌面和移动 PWA 客户端（可选，非必须）

**这条完全符合你「客户上手就能用」的要求。**

### 3.2 ⚠️ 第 2 条：白牌 —— 社区版不行，要付钱

**官方功能对比表（我实查）**：

| 功能 | Community（免费） | Starter（$10/用户 或 $20/并发） | Enterprise |
|---|---|---|---|
| 并发会话数 | **5** | 并发或命名用户 | 并发或命名用户 |
| 许可最低量 | — | < 25 | 25 |
| **商业使用（Commercial Use）** | **❌ 无** | ✅ | ✅ |
| **自定义品牌（Custom Branding）** | **❌ 无** | ✅ | ✅ |
| Web 分类过滤 | — | ✅ | ✅ |
| 自动扩缩容 | — | — | ✅ |
| 托管出口（Managed Egress） | — | — | ✅ |
| 开发者 API | — | ✅ | ✅ |
| 会话录制 | — | — | ✅ |
| 官方支持 | — | — | 需另购 |

**所以白牌是 Starter 起才有的功能。** 我上一轮说「社区版能白牌」——**这条也不准确。**

**⚠️ 而且即使付费版，「Powered By Kasm」的说明**：我上一轮提过一句，这轮没查到确切的官方原文说「最贵档能去掉」。**标注为未查实。**

### 3.3 ❌ 第 3 条：商业使用 —— 这是最关键的纠正

**Kasm 官方功能表写得很清楚**：

| 版本 | 商业使用 |
|---|---|
| Community（免费） | **不可用** |
| Starter（$10/用户 或 $20/并发/月） | ✅ 包含 |
| Enterprise | ✅ 包含 |

**而且不只「5 并发」这一个限制**：

> 「**Sessions cap is not the only limit. A business team of five people would still need a commercial tier even if it never exceeds five concurrent sessions.**」
> —— 就算你只有 5 个人、永远不超过 5 个并发会话，**商业用途也照样需要付费商业许可。**

**翻译成人话**：
- ❌ 「我只有 5 个客户，用免费版就够了」→ **不行**
- ✅ 「我只要拿它做生意卖给客户，就得买 Starter」

**真实成本**（必须算清楚）：

| 许可方式 | 价格 | 25 个客户时 |
|---|---|---|
| **并发会话**（$20/并发/月） | 按同时在线人数算 | 不划算（要按峰值买） |
| **命名用户**（$10/用户/月） | 按人头算 | **25 人 = $250/月** |

**注意 Starter 有「许可最低量 < 25」的限制** —— 意思是这个档位最多 25 个用户/会话。超过 25 就要谈 Enterprise（要报价）。

### 3.4 ❌ 第 4 条：凭据脱离 —— Kasm 做不到

回想你最初的要求（我在 `REMOTE-DESKTOP-AND-CODE-CHANNEL` 那份文档里记的）：

> 「哪怕不使用我们的平台，一台电脑也可以登陆，远控那些桌面」

**AWS WorkSpaces 能做到**（给标准 DCV/RDP 凭据，用任何远程桌面软件都能连）。

**Kasm 做不到**：
- Kasm 的凭据是 **Kasm 平台的账号**（可以接 LDAP / SAML / OIDC）
- 客户登录的是 `你的域名.com` 这个门户
- **脱离 Kasm 平台就没有「桌面」这个概念** —— 因为桌面本质是容器里临时生成的，不是一台常驻的机器

**但我认为这条可以重新考虑**：Kasm 给你的体验（打开网页就有桌面）比「给客户一串 RDP 账号密码让他自己配客户端」对普通人友好太多了。**「凭据脱离」是你早期从「不做锁定」角度提的，但对非技术客户来说，能用比能走更重要。**

**这条要你自己决策。**

### 3.5 ❌ 第 5 条：不是 Windows

**Kasm 默认给的是 Linux 桌面**：Ubuntu + XFCE、CentOS、Kali、Parrot 等。

**想要 Windows 怎么办**：Kasm 支持「连接到一台 Windows 机器」，方式有四种：
1. 固定 Windows 服务器（RDP）
2. 自动扩缩的 Windows 服务器
3. **Microsoft RDS**（多人共享一台）
4. **Azure Virtual Desktop**

**⚠️ 但这里有个大坑（Kasm 官方自己警告）**：

> 「**Microsoft explicitly disallows** running versions of Office later than 2019 on a VM in any cloud provider **other than Microsoft Azure**.」
> 「**Microsoft explicitly does not support** Windows 11/10 multi-session images running in any cloud provider **other than Microsoft Azure**.」
> 「Running of Windows 10/11 in a cloud provider other than Azure is **heavily restricted** by Microsoft.」

**翻译**：
- 想在**非 Azure** 的云上跑 Windows 10/11 多人共享 → **微软不允许**
- 结果就是：**每个用户一台 Windows 虚拟机** → 成本暴涨
- Office 2019 之后的版本，非 Azure 云上**明令禁止**

**而 Kasm 官方明确说**：「**Kasm does not provide support or assistance with licensing Microsoft products.**」—— 微软的许可证问题它不管。

**所以「Kasm + Windows」这条路 = 你还要单独解决微软的授权问题 + 单用户一台机器 = 成本不比 AWS 便宜。**

### 3.6 ⚠️ 第 6 条：成本 —— 比想象中贵

| 项目 | 成本 |
|---|---|
| Kasm 软件许可 | **Starter $20/并发/月** 或 **$10/命名用户/月** |
| 服务器 | **必须单独一台，8GB 起**（见第六节） |
| Windows（如果要） | 另算，且单用户一台 |

**25 个客户 = $250/月许可 + 服务器费用。** 这还没算你的人工。

## 五、那到底怎么办？我的建议

### 5.1 立刻能做的验证（不违规、不花钱）

**用 Kasm 社区版做内部验证 —— 这是合法的。**

官方许可原文：「built for individual users, non-profit organizations, **non-commercial use**」+「free for testing」。

**所以你可以**：
1. 在自己服务器上装社区版
2. **自己用 + 请 2–3 个朋友试用**（免费、非商业、5 并发以内 → 合法）
3. 验证一件事：**「客户到底会不会用云端桌面」**

**这是你最该先验证的假设**，我在上一轮文档里也说过。**验证它不需要商业许可。**

### 5.2 验证通过之后再花钱

**如果验证结果是「有人要用」** → 买 Kasm Starter（$20/并发/月），开始接客户。

**25 个客户以内**：Starter 够用（$20/并发 或 $10/人）
**超过 25 个**：要谈 Enterprise（报价制）

### 5.3 ⚠️ 成本对比（Kasm vs AWS）

假设 25 个客户：

| 方案 | 软件/许可 | 服务器 | 合计 |
|---|---|---|---|
| Kasm Starter（并发 10） | $200/月 | $50–100/月（要 8GB+ 机器） | **~$250–300/月** |
| AWS WorkSpaces（25 人） | 含在套餐 | — | **~$425/月** |

**Kasm 还是便宜一些，但没有「免费」这回事。**

## 六、⚠️ 你现在的服务器跑不动 Kasm

**官方硬件要求**：

| 项目 | 最低 | 推荐 |
|---|---|---|
| CPU | **2 核** | 4 核 |
| **内存** | **4 GB** | **8 GB** |
| 磁盘 | 50 GB | 更多（每个镜像几 GB） |

**⚠️ 关键**：官方**默认每个标准会话预留 2 核 + 2768MB 内存**。

**也就是说**：
- 4GB 机器 → **实际只够管理员测试 1 个轻量会话**
- 8GB 机器 → 舒适跑 2–3 个并发桌面
- 16GB → 4–6 个轻量会话

**托管服务商的实际建议**：「**Kasm Workspaces needs at least 8 GB of RAM**」+「它是一个专用服务器，**需要独占整个 VM，不能跟其他应用混装**」。

**对照你现在这台**：
- 新加坡 `66.42.56.29`，推测 2核2G 或 2核4G
- 而且它**同时跑着 Caddy + 应用 + Ollama**

**结论：现在这台装不了 Kasm。** 要另开一台 **8GB 内存起**的机器，约 **$24–48/月**（Vultr 新加坡）。
