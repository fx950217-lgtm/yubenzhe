## 第三节 · ⚠️ 最需要你知道的：原型画了 ≠ 实际有

**这是本节最重要的一条。**

我在设计稿（`design/ybz-mobile-ui.html`）里画了一些**看起来有、实际是空**的东西。Codex **诚实地标注了"未接入"**，但你翻原型时会以为有：

| 原型里画的 | 实际状态 |
|---|---|
| 钱包「**钱包 1 ▾**」可切换 | ❌ 不能切换（没有多钱包） |
| 币种「**$752.12 -0.59%**」行情 | ❌ 行情未接入，只显示数量不估值 |
| 分类 tab「**DeFi / NFT / 授权**」 | ❌ 三个都标注「尚未接入」 |
| 收款按钮 | ⚠️ 有按钮，无收款码页 |
| DApp 浏览器 | ⚠️ 是外链列表，不是内置浏览器（**故意**） |

**➡️ 两种处理方式，你选一个**：
- **甲**：让 Codex 把「未接入」的部分**从界面上撤掉**（不显示空 tab），界面上只留真有的 —— **更诚实，界面更干净**
- **乙**：保留位置但**明确标注「未接入」**（Codex 现在就是这么做的）—— **用户看得到未来规划**

我建议 **甲**：不显示空的东西，用户不会失望。
