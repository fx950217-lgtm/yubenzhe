============================================================
任务：AI 工作台「模型与工具」页 —— 全套配置清单落地
============================================================

背景
----
愚笨者的 AI 工作台已经定位为「AI 的安装管家」：帮不会折腾的人把 AI 装好、
把环境配好、把电脑连上。首页文案与「我的设备」页已经调整到位。

现在缺最后一块：客户点进「工作台 → 模型与工具」时，看到的还是空白/待接入，
没有一个真正能照着做的清单。本任务就是把「客户装 AI 需要的所有东西」
做成工作台里可见、可点、可复制的清单页。

本任务分四部分，请按顺序做，做完一部分再进下一部分。

============================================================
第一部分：先 commit（最紧急，必须最先做）
============================================================

工作区当前有大量未提交改动（改动文件数已超过 110 个），最后一次 commit
仍是 1a98e74（dev.7 时代）。这个状态已经连续多轮没有处理，存在丢失风险。

请在动手开发前，先完成一次干净的分组提交：

1. 先运行 git status，把改动分组归类（例如：远控设备桥 / 工作台文案 /
   成果分享 / 云电脑骨架 / 部署配置）。按功能分组提交，不要一个大 commit。
2. 【重要】提交前检查敏感文件，确认以下内容不进仓库：
   - yubenzhe-deploy/device-bridge/device-state.json（设备密钥，绝不能进仓库）
   - 任何 *.log、connector.pid、配对文件 *.json
   - .env 实际值（.env.example 可以进）
   - 任何 API Key、EMAIL_OTP_SECRET、DESKTOP_CRED_KEY 的真实值
3. 确认 .gitignore 覆盖以上类型。如果没覆盖，先补上。
4. commit 信息用中文简述改了什么。
5. 提交后运行 git log --oneline -10 并贴出结果。

如果发现敏感文件已经在暂存区，先从暂存区移除，再提交。

- 说明：装在自己电脑上，完全不花钱，不需要注册账号。

档位② 少量花费

- 花钱吗：按量付费
