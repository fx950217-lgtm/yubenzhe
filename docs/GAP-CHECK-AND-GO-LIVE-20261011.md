**第 3 点很重要，是个隐藏的坑**：

```js

```
**意思是：就算你配好了 Key，用本地测试档位启动，AI 还是关着的。**
因为本地档位（M0）是「隔离测试」用的，故意不接外部服务。

> **人话**：你现在用的 `localhost:18916` 那个档位，是**故意关掉一切真实服务**的测试档。
> 想真用，需要一个新的「自用档位」——这是一个小任务。

## 三、怎么「全部做完」让你能用 —— 三条路

### 路线 A：你自己在电脑上用（最快，今天就行）

**目标**：让 `localhost` 上的版本真的能调 AI、能注册收邮件。

要做三件事：
```
① 去 DeepSeek 官网拿一个 API Key（约 10 分钟，需充值最少金额）
② 叫 Codex 做一个「自用档位」启动脚本（区别于 M0 测试档）：
   - 不删 AI_API_KEY
   - AI_PROVIDER=openai、AI_MODEL=deepseek-v4-flash
   - 邮件可以先不接，用模拟码
③ 启动，然后真实做 3 件自己的活
```

**成本**：一个 Key 的钱（DeepSeek 很便宜）
**产出**：你能真正体验「告诉 AI 要什么 → 它干完 → 回来看结果 → 分享」

### 路线 B：让公网上线（让朋友能用）

在 A 完成的基础上，加：
```

⑤ 接真实邮件（否则朋友收不到验证码）
```

**成本**：一个邮件服务商的钱
**产出**：可以发给朋友用了
