# 愚笨者 · 「皇帝序列」命名规范

> 目的：把**工作台**和**设备**两套界面**融合成一套叫法**，让普通人（包括不懂技术的用户和海外用户）一眼看懂。
> 版本：2026-10-13 ｜ 适用：`tongban/`（手机端）+ `yubenzhe-desktop/`（电脑端）

---

## 一、为什么用「皇帝序列」

你原来的比喻是：

> **人是皇帝，愚笨者是太监，干活的 AI 是宰相，模型是参谋。**

这个比喻的**最大价值**是：它把"我在哪一层、我该点哪里"讲清楚了。

但直接叫"太监/宰相"**不能进产品界面**（不好听、不通用、海外也怪）。所以做法是：

**保留这套逻辑关系，换成普通人能接受的说法。**

核心关系不变 —— **你是发号施令的人，平台跑腿传话，AI 干活，模型出主意。**

## 三、为什么这么改（对照现在的叫法）

| 现在叫什么 | 问题 | 改成什么 | 为什么 |
|---|---|---|---|
| 「工作台」（Tab 名） | 太宽，什么都能叫工作台 | **工作台 → 保留**，但只是**壳**；里面的分类改成下面 | Tab 名保留用户已熟悉 |
| 「我的电脑」 | 和"电脑"的物理概念混在一起 | **我的机房**（整体）/ **工位**（单台） | "机房"暗示"很多台"，"工位"暗示"在干活" |
| 「添加设备」 | 设备是技术词 | **添一个工位** | 一边是"添人/添位置"，普通人秒懂 |
| 「AI 名单」 | 不说明干什么 | **我的干将** | 直接说这是干活的人手 |
| 「装机清单」 | 像购物清单 | **请军师** | 明确这是"请出主意的" |
| 「文件工具模板」 | 太长太技术 | **小工具** | 短，且已经暗示不需要 AI |
| 「执行中/需要你决策」 | "决策"太重 | **正在干 / 等你定夺** | 口语 |
| 「设备离线」 | 技术词 | **这台在打盹** | 带点温度，不吓人 |
| 「AI 状态待刷新」 | 技术词 | **干将状态待确认** | 一致 |

## 五、英文版（海外用户）

海外用户**不能用"皇帝/太监/机房"这套中国宫廷词** —— 文化不通。做法是**换一套他们熟悉的隐喻**，但**结构完全对应**。

### 5.1 核心隐喻：从「朝廷」换成「工作间 / 车间」

海外用户的直觉是 **Workshop / Studio / Team**，不是宫廷。所以：

| 层 | 英文名 | 直觉 |
|---|---|---|
| 你 | **Owner** | 主人/机主，最直接 |
| 平台 | **YBZ** | 品牌名，不翻译 |
| 一群设备 | **My Fleet** | "舰队"，海外 Dev 圈很熟 |
| 单台设备 | **Workstation** | 工作台，通用词 |
| 只看不干 | **Remote** | 遥控器 |
| 干活的 AI | **Worker** | 干活的 |
| 出主意的模型 | **Advisor** | 顾问 |
| 一次任务 | **Task** | 通用 |
| 要你拍板 | **Needs Your Call** | 要你拍板 |
| 干完的东西 | **Deliverable** | 交付物 |

### 5.2 界面英文对照

| 中文 | 英文 |
|---|---|
| 我的机房 | **My Fleet** |

### 5.3 ⚠️ 海外版用词的三个坑

1. **"太监"绝对不能出现** —— 英文里 eunuch 是极负面的词，会毁掉品牌
2. **"皇帝"也别用** —— emperor 在欧美语境=独裁者，敏感
3. **"Fleet" 用得好** —— 但注意它暗示"很多台"，如果用户只有 1 台，**要说 Workstations 而不是 Fleet**（或者干脆只用 "My Devices" 更保险）

**保险做法**：
- 设备**≥2 台** → 显示 **My Fleet**
- 设备**=1 台** → 显示 **My Workstation**

## 六、⚠️ 一个必须提醒你的现实问题

**「皇帝序列」这套名字，只适合你自己用，不适合做产品的默认界面。**

原因：

| 问题 | 说明 |
|---|---|
| **1. 宫廷词在中文语境是"等级制"** | "皇帝/太监/干将"暗示身份高低，会让人觉得产品在**分等级**；大众用户会困惑"我是皇帝，那它是我的仆人吗" |
| **2. 海外完全不通** | 已说明 |
| **3. 和现在已有的用语冲突** | 现在产品里已经有"工作台/我的电脑/AI 名单"等一批词，全改 = 大批文案返工 + 测试要改 |

**所以我的真实建议是：**

### 方案 A（推荐）：**只用"机房/工位/干将/军师"这四个中性词**

去掉"皇帝/太监"（不出现在界面），保留**"机房 → 工位 → 干将/军师"**这条**空间-角色**线。因为：
- ✅ "机房/工位"是**空间词**，不是**等级词**，普通人理解成本低
- ✅ "干将/军师"是**角色词**，一个动手一个动脑，区分清楚
- ✅ **海外也能对**：Fleet → Workstation → Worker/Advisor

**"皇帝"这个逻辑你自己心里装着就行**（用来理解产品分层），**但不出现在界面上**。

### 方案 B：全套宫廷命名

把"皇帝/太监/干将/军师"全套做进界面。**只建议在"关于"页或内部文档里用**，当作品牌的个性彩蛋。

## 八、一句话总结

| 问题 | 答案 |
|---|---|
| 为什么改？ | 现在"设备/电脑/AI/工具"混着叫，普通人分不清 |
| 改成什么？ | **机房 → 工位 → 干将 / 军师**（空间 + 角色） |
| 皇帝序列还用吗？ | **用，但只作为你心里的分层逻辑**；界面上用中性词 |
| 海外怎么叫？ | **Fleet → Workstation → Worker / Advisor** |
| 谁是太监？ | **愚笨者本身**；但界面上它就叫"管家 / YBZ" |
