### 1.2 现在缺的（本任务要做的）

**缺的是这样一条通道**：

```
❌ 现在：手机 → 服务器 → 电脑屏幕（人手动点）        ← 有，但人要盯着屏幕点
❌ 现在：手机 → 服务器 → 云端小模型（只能聊天）       ← 有，但干不了活
✅ 要做的：手机打字 → 服务器 → 电脑上的 Codex/Claude 自动执行 → 结果回手机
           支持中途传文件、收文件
```

**➡️ 一句话：现在的远控是"我看到屏幕我自己点"，要做的这条是"我说一句话它自己干"。**

### 1.3 ⚠️ 一个必须分清的区别（避免做歪）

| | 云端模型聊天（已有） | 要做的本机 AI 通道 |
|---|---|---|
| 跑在哪 | **你的服务器**（Ollama） | **用户的电脑**（Codex CLI） |
| 能干什么 | 只能吐文字 | **能读文件、改代码、跑命令** |
| 电脑关了 | 没事 | **AI 下线** |
| 服务器看到什么 | 全部对话内容 | **只有出入的消息文本** |
| 有成本吗 | 服务器算力 | **用户自己的 Codex 额度** |

**➡️ 核心原则（不可违背）：服务器只做"消息中转"，不接触文件内容、不碰用户的 AI 账号。**

## 三、要做的功能（分三层，按优先级）

### 3.1 🟢 P0：AI 任务通道（核心，必做）

**目标**：手机 ybz 聊天窗口里发一句自然语言 → 云端电脑（或用户自己的电脑）上的 Codex 执行 → 结果流式回手机。

**数据流**：
```
① 手机 ybz 聊天窗口
      ↓ POST /api/ai-channel/send  { deviceId, prompt, requestId }
② yubenzhe-deploy 服务器（只转发，不存文件内容）
      ↓ 写进待执行队列
③ 电脑上的连接器 poll 取走任务
      ↓ spawn codex.exe exec --json -C <限定目录> "<prompt>"
④ Codex 执行（读文件/改代码/跑命令）
      ↓ 增量输出
⑤ 连接器把增量回传服务器 → 服务器转发 → 手机流式看到
```

**必需的安全约束（一条都不能少）**：

| # | 约束 | 理由 |
|---|---|---|
| 1 | **可执行目录由连接器启动参数指定，请求不能改** | 防手机端 `-C "C:/"` 乱来 |
| 2 | **prompt 长度上限 8000 字符** | 防滥用 |
| 3 | **单任务超时上限 10 分钟**，超时 kill 进程 | Codex 可能挂住 |
| 4 | **并发上限 1**（同时只跑一个任务） | 防把电脑跑满 |
| 5 | **沙箱默认 `workspace-write`**，禁止 `danger-full-access` | Codex 自己也能改文件，必须圈住 |
| 6 | **任务队列深度上限**（建议 5） | 防堆积 |
| 7 | **日志不记录 prompt 全文**，只记 taskId + 长度 | 隐私 |
| 8 | **同一 requestId 幂等**（照抄 `personal-devices.mjs` 第 71-73 行） | 防重复执行 |
| 9 | **撤销设备后立即拒绝**（照抄第 53 行 `e.status===401` break） | 安全 |
| 10 | **服务器不保存任务输出全文**，只存最近 N 条（建议 50） | 省空间 + 隐私 |

**前端要求（手机端）**：
- 在现有「我的设备」页里，设备卡片增加一个入口：**「和它聊天」**（区别于现有的「查看并控制电脑」）
- 聊天界面复用现有 `cloud-chat.js` 的样式和交互模式（消息列表 + 输入框 + 流式更新）
- 每条回复旁标注来源：**「来自：我的电脑 · Codex」**
- 设备离线时，输入框禁用 + 明确提示「电脑离线，请启动连接器」
- 顶部显示：`● 我的电脑 · Codex 在线` / `○ 离线`

### 3.2 🟡 P1：文件收发（用户明确要求）

**用户原话**：「发送文件」

| 方向 | 要求 |
|---|---|
| **手机 → 电脑** | 手机选文件上传 → 服务器转存 → 连接器取走 → 落到电脑指定目录（如 `<允许目录>/inbox/`） |
| **电脑 → 手机** | Codex 产出的文件 → 连接器上传 → 手机下载 |

**约束**：
- 单文件上限 **20MB**
- **服务器上的文件 24 小时后自动删**（只做中转，不长期存）
- 文件名必须清洗（防路径穿越 `../`）
- 落盘目录必须在"允许目录"之内
- ⚠️ **服务器不解析文件内容**（只当中转管道）
- ⚠️ **用户明确要求"云机可以隐藏那些 AI 在后台"** → 所以文件交互也走这条通道，不暴露 Codex 原生界面

### 3.3 🔴 P2：不要做的（明确划界）

| 不做 | 原因 |
|---|---|
| 平台托管用户的 AI API Key | 信任崩塌 |
| 服务器主动连用户电脑 | 安全噩梦（必须电脑主动连） |
| 多 AI 群聊自动互相回复 | **会烧光额度**，且需要先设计讨论协议 |
| 让 Codex 以 `danger-full-access` 跑 | 等于把整台电脑交出去 |
| 界面里出现「一键自动安装 Codex」按钮 | 装不了（登录+验证码无法自动化），写了就是骗人 |
