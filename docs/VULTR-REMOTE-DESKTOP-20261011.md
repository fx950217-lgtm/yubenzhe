# 四、⚠️ 但有几个坑必须知道

## 坑 1：Vultr 的 Windows 不能自己装

**官方原文**：
> 「Windows ISOs are not supported.」（不支持 Windows ISO）
> 「Due to licensing requirements, we cannot provide support for custom Windows installations.」（由于授权限制，不支持自定义 Windows 安装）
> 「The majority of Windows licenses are not valid for cloud server deployment.」（**大部分 Windows 授权不适用于云服务器部署**）

**➡️ 意思：你只能用 Vultr 提供的授权镜像，不能装自己的 Windows 11。**

**⚠️ 所以：想要 Windows 11（不是 Server）→ Vultr 做不到。** 这是和 Shadow PC 的本质区别。

## 坑 2：Windows Server ≠ Windows 11

**Vultr 给的是 Windows **Server**（2016/2019/2022/2025）。**

| | Windows Server | Windows 11 |
|---|---|---|
| 桌面体验 | ✅ 有（Desktop Experience） | ✅ 有 |
| 微软商店 | ⚠️ 没有 | ✅ 有 |
| 消费级 AI 软件 | ⚠️ 部分装不上 | ✅ 都行 |
| 授权 | 云服务商提供 | ❌ Vultr 不给 |

**➡️ 结论：如果你要装「消费级 AI 桌面软件」（比如某些需要 GPU 驱动的），Windows Server 可能装不上。**
**VDI 方案（带 GPU）能缓解这个问题，但系统还是 Server。**

## 坑 3：⚠️ 关机照样计费

**Vultr 是按小时计费，但「关机」不等于「不计费」—— 必须「销毁」才停。**

**➡️ 客户如果不销毁，账单继续跑。这对你做转售是个真实风险。**

## 坑 4：⚠️ DDoS 会直接拔网线

**Vultr 的 DDoS 防护是「黑洞（Blackholing）」** —— 一旦被攻击，**IP 直接被拉黑，服务器完全离线**。

**➡️ 如果客户被攻击，他的机器会直接断网，直到攻击结束。** 这一点要提前跟客户说清楚。
