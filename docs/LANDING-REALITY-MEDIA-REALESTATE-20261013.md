## 二、先纠正三个可能想错的地方

### ❌ 想错 1：「愚笨者是总指挥，它自己能调所有 AI」

**实际不是。** 愚笨者不"调用"这些 AI，它做的是：

> **把你在手机上说的话，原样交给电脑上已经装好的那个 AI，然后盯着它干。**

它像**传话的人 + 盯着的人**，不是"AI 的大脑"。
所以：**电脑上装了什么 AI，它就能用哪个；没装的，它变不出来。**

### ❌ 想错 2：「手机派活 → Codex 就会去操作其他软件」

**做不到全部。** 必须分清两种活：

| 活的类型 | 例子 | Codex 能不能干 |
|---|---|---|
| **文件类**（读文件、改文件、生成文件） | 改图、整理表格、写文案存成文档、改代码 | ✅ **能，而且这是它的强项** |
| **图形界面类**（必须点鼠标点某个软件） | "打开 XX 软件，点那个导入按钮，帮我导入 200 条客户名单" | ❌ **不能**（要靠你远程点，见第四节） |

**为什么？** 因为 Codex 跑起来的时候，**图形界面那部分能力被主动关掉了**（这是安全设计，代码里写死的）。

### ❌ 想错 3：「填一次机器码，一劳永逸」

**不是一次性的。** 每次手机给电脑派活：
- 电脑那边要**当场还醒着、连着网**
- 每次授权**最多 10 分钟**，超时自动停
- **断网最多 15 秒**就把这件事停掉

这是**故意的**——防止你手机被人拿了乱指挥你的电脑。

## 三、你的场景逐段跑一遍（房产 / 传媒引流）

### 场景 A · 房产：把 200 条客户名单做成房源匹配表

**你在外面跑盘，手机派活**：

> 「用 `D:\房产\客户表.xlsx` 和 `D:\房产\房源表.xlsx`，按客户预算和意向区域匹配一下，输出一张匹配表，每条给个推荐理由。」

**电脑那边实际发生的事（逐步）**：

| 步 | 谁在做 | 做什么 |
|---|---|---|
| 1 | 手机 | 消息加密发到服务器 |
| 2 | 电脑 | **它主动连着**服务器（不是服务器去连它），发现新任务 |
| 3 | 电脑 | 校验：这个任务确实是你派的、没过期、没被别人改过 |
| 4 | 电脑 | 在一个**隔离的工作目录**里启动 Codex，把你说的话原样递过去 |
| 5 | Codex | 读两个 Excel，写一段脚本，跑出匹配表，存到工作目录 |
| 6 | 电脑 | 把结果告诉 Codex-runner，扫描本机有没有新文件 |
| 7 | 电脑 | 把结果文件**加密传回**服务器 |
| 8 | 手机 | 你看到：「✅ 匹配表做好了，87 条」+ 下载按钮 |

**你在手机上全程只需要：说一句话 → 等通知 → 点一下。**

**⚠️ 但这里有个坑（必须知道）**：
Codex 干活是在**它自己的隔离目录**里干的，它能不能读到 `D:\房产\` 里的文件，
取决于**工作目录设在哪**。
- 如果工作目录设成 `D:\房产\` → ✅ 能读能写
- 如果设成默认的隔离目录 → ⚠️ 它看不到你的 `D:\房产\`

**这个目录在哪设？** 现在向导里只**显示**（不给改），是自动分配的。
**这是要改的第一个点**。

---

### 场景 B · 传媒引流：批量做 50 条文案 + 改 100 张图

**你在吃饭，手机派活**：

> 「`D:\引流\素材\` 里 100 张图，统一加水印『XX 房产』，右下角，透明度 40%；
> 再写 50 条小红书风格的文案，主题是"学区房避坑"，每条不超过 120 字。
> 全部做完一起给我。」

**电脑那边**：
- Codex 读目录 → 用脚本批量加水印 → 存到新目录
- 写 50 条文案 → 存成文档
- 回传结果

**⚠️ 坑 2：一次说你想要几件事，现在是被当成一件事处理的。**
它会把整段话交给 Codex，Codex 会尽量全做完，但**你在手机上看到的是一条进度，不是三条分开的**。
如果你想知道"图片做到第几张了"，现在**看不到细节**。

---

### 场景 C · 引流：让 Codex 去某个平台上发内容

**这是最容易误会的一条。**

你说"通过 Codex 去操作其他软件做命令"——**这里要分开看**：

| 你想做的 | 能不做 |
|---|---|
| 让 Codex **生成**内容（文案、图片、视频脚本） | ✅ 能 |
| 让 Codex **存成文件**，你自己去发 | ✅ 能 |
| 让 Codex **自动打开某个 App 帮你发出去** | ❌ **现在不能** |
| 让 Codex **调某个平台的 API 自动发** | ⚠️ 技术上能，但要那个平台**有 API**，而且你要给它 API Key |

**❌ 为什么"自动打开 App 帮你发"做不到？**
因为 Codex 的**插件、浏览器操作、电脑操作**这些能力被**主动禁用了**（安全考虑）。
代码里明确关掉了：`browser_use`、`computer_use`、`plugins`。

**那怎么办？** 两条路：
1. **你自己远程点**：手机上打开远程桌面，你亲手点那个"发布"按钮（第三节场景 D）
2. **给它 API**：如果平台有开放接口（比如有的自媒体平台有），Codex 可以写脚本调接口

---

### 场景 D · 必须"手点一下"的时候

比如：某个引流平台上，AI 写好了内容，但发布要点一个图形按钮，还有验证码。

**这时候走远程桌面**：

```
手机 → 你点「打开桌面」
     → 看到电脑画面
     → 你亲手点那个"发布"按钮
     → 关掉，继续干别的
```

**这是必须的能力，而且现在有基础**（画面回传 + 点击 + 键盘）。

**⚠️ 但目前是"画面过服务器"的，有成本**（你定过零成本，所以这块要改成直连）。

## 四、Codex 能指挥谁？（这个答案可能让你意外）

**现在真正能派活的，只有两个：**

| AI | 装了吗能认出来 | 能派活 | 备注 |
|---|---|---|---|
| **Codex** | ✅ | ✅ **能** | 主力，能力最强（能读写文件、跑命令、写脚本） |

**➡️ 也就是说：你电脑上装再多 AI，现在真正能干活的只有 Codex 一个。**

你说"给其他的软件做命令"——**这个能力现在等于 0**。
这不是没做，是**还没做**（Claude 和 WorkBuddy 的执行适配是空着的）。

## 五、房产 / 传媒引流这两个行业，真正能落地的清单

### 🟢 现在就能用（Codex 的强项）

| 干什么 | 具体例子 |
|---|---|
| **处理文件** | 客户表匹配房源、订单整理、批量改文件名、图片加水印 |
| **生成内容** | 房源描述、引流文案、朋友圈话术、视频脚本 |
| **算账** | 佣金计算、成本利润、贷款月供测算 |
| **写代码** | 做个小的内部工具（比如房源查询页） |
| **整理数据** | Excel 合并、去重、分类、生成报表 |

### 🟡 要等一等（还没做）

| 干什么 | 缺什么 |
|---|---|
| 让 **Claude / WorkBuddy** 干活 | 执行适配没接通 |
| **多件事**分别看进度 | 现在只有一条进度 |
| 派活时**指定工作目录** | 向导里只显示不给改 |

| 自动**发布**到平台 | Codex 的浏览器/电脑操作被禁用 |

### 🔴 做不到（要换思路）

| 干什么 | 为什么 | 替代方案 |
|---|---|---|
| 让 AI **替你操作任意软件**（点按钮、填表单） | 安全设计禁用了 GUI 操作 | **你远程点一下** |
| 让 AI 自动**登录**到某个平台 | 有验证码，绕不过 | 同上 |
| AI 帮你**绕过平台风控** | — | 不做，这是红线 |

## 六、你要的那个"房产 + 传媒引流"工作流，长什么样

**这是一个真实能跑的形态**：

```
【电脑上（一直开着）】
  ├─ Codex（干活的主力）
  ├─ Claude（暂时只能聊天）
  ├─ Ollama（本地模型，能聊天）
  └─ 愚笨者（连接器）→ 生成机器码 YBZ-XXXX-XXXX
                          ↓ 手机输入机器码
【手机上（你在外面）】
  └─ 愚笨者
      ├─ 说一句话 → 电脑上的 Codex 开始干
      ├─ 干完了 → 手机弹一次
      ├─ 要你拍板 → 手机弹个卡，你点一下，它接着干
      └─ 需要手点 → 远程开桌面，你点一下
```

**一天可能是这样的**：

| 时间 | 你在哪 | 手机做什么 | 电脑（Codex）做什么 |
|---|---|---|---|
| 09:30 | 去客户家的路上 | 派活："把昨天 30 组带看记录整理成表，标出有意向的" | 读记录 → 生成表 |
| 10:10 | 客户家门口 | 收到通知，点"看结果" | —（已完成） |
| 12:00 | 吃饭 | 派活："写 20 条周末看房活动的朋友圈文案" | 写文案 → 存文档 |
| 15:00 | 带看路上 | 收到"需要拍板：这 20 条里 3 条提到具体小区名，要发吗？" | 卡住等你 |
| 15:02 | 路边 | 点"改掉小区名，别的照发" | 改完 → 存好 |
| 19:00 | 家里/外面 | 派活："把今天做的图加水印，发我" | 批量处理 |
| 21:00 | 沙发上 | 收到：图片做好了 | — |
| 22:00 | 睡前 | 派活："明天要发的 5 条视频，脚本写好" | 写脚本，收工 |

**➡️ 一整天，你没打开过电脑一次。**

## 八、一句总结

> **你想要的场景，地基已经在，主路能走通：
> 手机派活 → 电脑上 Codex 干活 → 手机看进度 → 关键处停下来问你。
>
> 三块砖还缺：
> ① Codex 干活时**够不够得着你的业务文件**（工作目录）
> ② **别的 AI（Claude/WorkBuddy）还不能派活**
> ③ **需要点鼠标的活，还得你远程点**
>
> 其余的（进度提醒、决策卡、机器码配对、文件回传）——**已经实测能跑。**」
