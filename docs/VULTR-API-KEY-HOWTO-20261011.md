# 〇、⚠️ 安全说明（务必先读，30 秒）

## 这个 Key 能干什么

**Vultr 的 API Key 权限分两种，我要的是「受限的那个」：**

| 权限类型 | 能干什么 | 我要吗 |
|---|---|---|
| **Full Access**（完全访问） | 能改账单、能改支付方式、能删账号 | ❌ **不要给我这个** |
| **Limited / Read-Write 限权** | ✅ 能开机器、销毁机器、装系统 | ✅ **给我这个** |

**⚠️ 但我要诚实说**：Vultr 的 API Key 权限粒度比较粗 —— **默认生成的 Key 通常是完整权限的**。所以真正的保护靠这三条：

## 你的三道保险（都做到了就安全）

1. **✅ 用「受限 IP」限制** ⭐ **最重要**
   - Vultr 创建 Key 时可以填「Allowed IPs」
   - **填上我运行电脑的公网 IP** → 这个 Key 在别的 IP 上**直接用不了**
   - ⚠️ 但这样我换网络就失效 → 如果你觉得麻烦可以跳过，靠下面两条

2. **✅ 随时可作废**
   - 我要的东西装完，你**直接回 Vultr 后台把这个 Key 删掉**
   - **删掉 = 立刻失效**，一秒的事
   - **➡️ 我的建议：装完之后你就删掉它**

3. **✅ 不给付款方式的操作权限**
   - 你**不要**把 Vultr 的账号密码、支付密码给我
   - 只要 API Key

**⭐ 一句话**：**API Key 给一次，用完即删。** 这比给账号密码安全得多。

# 一、创建步骤（5 步）

## 第 1 步：进 API 页面

**在 Vultr 后台：**

1. 点**右上角你的头像**（或用户名）
2. 在下拉菜单里找 **API**
   - ⚠️ 如果没看到，看左侧菜单的 **Account** → **API**

**或者直接访问**：`https://my.vultr.com/settings/#settingsapi`

**➡️ 你会看到「Personal Access Token」或「API Keys」区域**

---

## 第 2 步：创建新 Key

1. 找到 **Personal Access Token** 区块
2. 点 **Enable Personal Access Token**（或 **Add API Key**）
3. 如果弹窗要你**再输一次账号密码** → 输入（这是正常的安全确认）

---

## 第 3 步：⚠️ 设置 IP 白名单（可选但推荐）

**会看到「Allowed IPs」或「IP Whitelist」这一栏：**

| 你的选择 | 说明 |
|---|---|
| **留空** | 任何 IP 都能用这个 Key（⚠️ 安全性低一些，但方便） |
| **填 IP** | 只有这个 IP 能用（✅ 更安全，但换网络就失效） |

**⚠️ 如果我这边给你填 IP，我需要知道运行电脑的公网 IP。** 我可以帮你查（见下面第 6 节）。

**➡️ 如果你嫌麻烦，就先留空，装完立刻删 Key（这样也安全）。**

---

## 第 4 步：复制 Key ⚠️ 只显示一次

1. 点 **Create / Generate**
2. **⚠️⚠️ Key 会显示出来，但只显示一次**
3. **立刻复制整串**（通常是一长串字母数字）
4. **粘贴到一个安全的地方**（比如记事本，先存着）

**⚠️ 如果关掉页面就再也看不到这个 Key 了** → 只能删掉重建。

---

## 第 5 步：注意权限设置

**Vultr 有些版本会问你要什么权限范围：**

| 选项 | 选它 |
|---|---|
| **Read / Write**（读写） | ✅ **选它**（要开机器必须读写） |
| Read Only（只读） | ❌ 只能看，开不了机器 |
| Full（完全） | ⚠️ 能开机器，但也能碰账单 |

**➡️ 如果有 Read/Write 选项就选它；如果没有权限选项，那默认就是完整 Key（靠"用完即删"保护）。**
