## 🎯 第零节 · 产品灵魂（一切判断的尺子）

> **人做决策，机器干活。**

判断任何功能该不该做，只问一句：

| 这是「决策」还是「干活」？ | 怎么办 |
|---|---|
| **决策** | 交给人 —— 做成**一个显眼、单一、能点一下的卡片** |
| **干活** | 交给机器 —— 人不用操心 |

**平台方针（最高优先级，覆盖旧代码）**：
- **零收费**：无购买/充值/订阅/余额/提现/套餐/**价格数字**

- **不做出租/租赁/卡密/租期**
- **不接任何云服务商** —— 客户自备设备（自己的电脑或自己买的服务器）

```css
  /* 涨跌：涨红跌绿（中国习惯） */

  --t1:rgba(0,0,0,.90); --t2:rgba(0,0,0,.60); --t3:rgba(0,0,0,.40); --t4:rgba(0,0,0,.26);

         "Microsoft YaHei UI","Microsoft YaHei","Source Han Sans CN",sans-serif;

```

### ⚠️ 六条硬规范（不许违反）

| # | 规范 | 说明 |
|---|---|---|
| 1 | **字重只有 400 / 600** | ❌ 禁止 500 / 700。**已有代码里的 500 要清掉** |
| 2 | **行高 = 字号 + 8** | 14px→22px，16px→24px，20px→28px。❌ 不要用固定倍数 |
| 3 | **文字色用透明度 token** | 主 t1 / 次 t2 / 辅 t3 / 占位 t4。❌ 不要写死灰色 |
| 4 | **触控目标 ≥ 44px** | 所有可点元素最小高度 44px |
| 5 | **正文对比度 ≥ 4.5:1** | t1/t2 达标；t3/t4 只能用于时间戳、箭头等非关键信息 |
| 6 | **图标统一** | 24×24 viewBox · stroke 1.8 · round cap/join · 彩色底 32×32 圆角 12px |

### ⚠️ 三个皮肤要一起改

项目现有 **白天 / 黑天 / 护眼** 三套皮肤（`theme-skins.css`）。**新增 token 后必须三套都验证**，不能只改白天。

### U0 验收标准（5 项）
1. 上述 token 已落到全局 CSS 变量
2. 三套皮肤（白天/黑天/护眼）都有对应值
3. 全项目搜 `font-weight:500` / `font-weight:700` → **归零**
4. 全项目搜写死的灰色（如 `#666` `#999`）→ 尽量换成 token
5. 有测试断言「字重只用 400/600」

## 📱 第二节 · 五个页面重构（U1～U5）

**⚠️ 每个页面都先打开 `design/ybz-mobile-ui.html` 对应页签对照。**

### U1 · 消息页（首页）—— 最重要的改动

**现状问题**：AI 入口藏在「工作台 → 我的设备 → 点设备 → 聊天」，**用户在消息首页找不到 AI**。

**要改成**（对标微信把「元宝」做成普通聊天项）：

1. **AI 就是消息列表里的一项**：
   - 头像 = 电脑，左上角带 **`AI` 小角标**
   - 名字 = 设备名（如「老张的电脑」）
   - 点进去 = 和这台电脑的 AI 单聊
2. **顶部右侧 + 号**（现在有了吗？确认在）→ 弹「发起讨论组」
3. 讨论组项显示 **`AI×N`** 标签
4. **底部小字**：「AI 助手只有你能看到 · 不会出现在别人的列表里」

**⚠️ 红线**：AI 不是好友。它只出现在**本人**的消息列表，别人搜不到、看不到。

### U2 · 讨论组页（新增）

**点消息列表的讨论组 → 进群聊页**：

1. 顶部：返回 + 群名 + 「N 人 · M 个 AI」
2. **成员栏**：人 + AI 头像排一起，**AI 成员显示备注名**（如「选品顾问」）并用品牌色
3. 群消息流：AI 发言**带左侧色条** + 标「选品顾问 · AI」
4. **⭐ 点 AI 成员头像 → 拉出单独聊天框**（进 U1 的单聊页）

### U3 · 工作台（中心）

1. 顶部：标题 + **右上角 + 号**（添加设备，弹机器码输入）
2. **我的电脑**：横向滚动卡（设备名 + 在线状态 + 正在干啥）+ 一张虚线「添加设备」卡
3. **正在执行**：任务卡 + 进度条
4. **需要你决策**：决策卡（两个按钮）
5. **最近完成**：打勾图标 + 时间 + 结果数
6. 底部：派活输入框

### U4 · 钱包（对标 TP，整合成一页）

**布局严格按这个顺序**：

| 位置 | 内容 |
|---|---|
| 卡片 | 渐变卡：钱包名 + 「立即备份」+ 金额 + 眼睛图标 |
| 第二行 | **转账 · 收款 · 兑换 · 更多**（四个方形按钮） |
| 第三行 | 分类 tab：**资产** / DeFi / NFT / 授权 |
| 下面 | **币种列表**：图标 + 名称 + 行情价 + 涨跌% + 数量 + 估值 |

**⚠️ 红线**：不出现充值 / 提现 / 购买 / 价格套餐。**涨红跌绿**。

### U5 · 发现 / 我的（对标微信）

**发现**（分组列表，一行一个入口）：
- 组1：朋友圈 · 认识新朋友 · 收藏
- 组2：**DApp 浏览器** · 扫一扫

**我的**（顺序按使用频率，**不许随便排**）：
1. 头像卡（名 + ID + 二维码图标）
2. **我的电脑与 AI**（显示「N 台在线」）← 最高频，**必须在第二位**
3. 收藏 · 朋友圈
4. 账号与资料 · 安全中心 · 外观与主题
5. 帮助与反馈 · 关于愚笨者
6. **设置**（单独一组，最下）

## ⚙️ 第三节 · 核心功能（F1～F4）

### F1 · AI 单聊入口提到消息页

**现状**：单聊功能已有（`ai-channel-chat.js`），但入口在设备页。

**要做**：
- 消息页的 AI 项 → 点进单聊（复用现有 `ai-channel-chat.js`）
- 单聊页顶部显示：「设备名」+「AI 名」+「**只有你能看到这台设备**」

### F2 · 建讨论组：拉 AI + 给 AI 备注 ⭐

**现状**：群聊没有「拉 AI 进群 + 备注」的能力。

**要做**：
1. 建群/群设置里，成员列表**同时列出人和 AI**
2. 每个 AI 成员可以填**备注**（如「选品顾问」= 老张的电脑·Codex）
3. 群里 AI 发言显示**备注名**（不是显示"Codex"）

**数据要求**（新迁移 `026-*.sql`，编号先核对）：
- 群成员表要能标记「这是 AI 成员」+ 存备注
- ⚠️ **AI 不建成账号**（`accounts` 表不许插 AI）
- ⚠️ 消息仍由**设备主人代发**，附 `provider` + `device_id`（沿用现有设计）

**⚠️ 边界**：AI 只能进**我的**讨论组，**不能被别人拉进他们的群**。

### F3 · 点群内 AI → 拉出单独聊天

**要做**：讨论组页点 AI 成员头像 → 打开和这台设备的单聊（复用 F1 的单聊页）。

### F4 · 决策闭环（干到关键处停下来问）⭐ 核心

**现状**：**没有**。AI 干完了就说完了，不会停下来等确认。

**要做**：
AI 干到需要人拍板的节点时，**主动停下**，在会话里发一张决策卡：

```
┌─────────────────────────┐
│ 需要你拍板               │
│ 300 张已改好，先看样张？  │
│ [ 再改一下 ] [ 导出 ]    │
└─────────────────────────┘
```

- 你在任一设备上点一个 → AI 继续
- ⚠️ **必须由人点**，不能自动继续
- ⚠️ 决策结果要落库（可追溯）
- ⚠️ 要有**超时**（比如 30 分钟没人点 → 挂起，不自动执行）

### F · 验收标准
1. 消息页能看到 AI 项，点进去是单聊
2. 建群能拉 AI + 填备注
3. 群里 AI 发言显示备注名
4. 点群内 AI 头像能拉出单聊
5. **决策闭环能走通**（AI 停 → 弹卡 → 点 → 继续）
6. **AI 没有变成账号**（`accounts` 表查不到 AI）
7. **AI 不进别人的群**
