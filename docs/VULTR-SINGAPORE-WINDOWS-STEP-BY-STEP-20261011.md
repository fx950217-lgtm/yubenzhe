# 一、⭐ 完整操作步骤（照着点）

## 第 1 步：进入部署页

1. 登录 Vultr：`https://my.vultr.com`
2. 看**右上角**，点 **「+」号**（或蓝色按钮 **Deploy New Server**）
3. 如果看不到「+」，点顶部菜单 **Products** → **Deploy New Server**

---

## 第 2 步：选服务器类型

**会看到几个大卡片，选这个：**

| 选项 | 选它吗 |
|---|---|
| **Cloud Compute - Shared CPU** | ✅ **选这个**（最便宜，够用） |
| Cloud Compute - Dedicated CPU | ❌ 贵，不需要 |
| High Frequency | ⚠️ 性能好但更贵（测试可用） |
| Cloud GPU | ❌ 太贵（VDI 才需要） |
| Bare Metal | ❌ 贵得多 |

**➡️ 点「Cloud Compute - Shared CPU」**

---

## 第 3 步：选机房位置 ⭐（选新加坡）

**找到 Location / 位置那一栏，搜「Singapore」或在下拉里找：**

```
📍 Singapore (SG)   ← 选这个
📍 Tokyo (JP)       ← 备选（延迟也很低）
📍 Osaka (JP)       ← 备选
```

**⚠️ 为什么选新加坡**：
- 它是最中立的地区（OpenAI/Claude/Gemini 全支持）
- 离越南最近（30-50ms）
- **日本也是好选择**（延迟接近，且是 VDI 有 GPU 的机房之一）

**➡️ 点 Singapore**

---

## 第 4 步：选操作系统 ⭐（这里有坑）

**切到「Operating System」标签栏，然后：**

1. 点 **Windows** 图标
2. 会列出：
   - **Windows Server 2022 Standard** ← ⭐ **推荐选这个**
   - Windows Server 2025 Standard（更新，也可以）
   - Windows Server 2019 / 2016（老版本）

**⚠️ 注意别选错**：
- ⚠️ **不要选带「Core」的**（如 Windows Core Server）→ **它没有图形界面！** 你连桌面什么都看不到
- ✅ 要选 **Standard / Datacenter** 版本（**带 Desktop Experience，有完整桌面**）

**➡️ 选「Windows Server 2022 Standard」**

**⚠️ 关于授权**：Vultr 会自动加上 Windows 授权费，**你不用做什么**，账单里会自动包含。

---

## 第 5 步：选配置（Plan）

**往下滚到 Plan 区，选：**

| 用途 | 选哪个 | 月费 |
|---|---|---|
| **只测延迟** | 1核 2G / 55GB | **$26** ⭐ |
| **要装 AI 工具** | 4核 8G / 160GB | $104 |
| 别选 | 2核 2G | $47（最不划算） |

**⚠️ 提示**：Vultr 页面会显示**基础价**（如 $10），**加上授权后才是实际价**。
**认准右侧 Summary 里显示的最终金额。**

---

## 第 6 步：⚠️ 关掉不需要的附加项（省钱）

**会看到几个 Additional Features，建议全部不勾：**

| 项目 | 建议 | 原因 |
|---|---|---|
| **Auto Backups** | ❌ **不勾** | 加收 **20%** ⚠️ |
| **IPv6** | ✅ 可勾 | 免费 |
| **Cloud-Init / Startup Script** | ❌ 不勾 | 用不到 |
| **VPC** | ❌ 不勾 | 用不到 |
| **Firewall** | ⚠️ **建议勾** | 见下方安全提醒 |

---

## 第 7 步：⚠️ 配防火墙（重要，防被黑）

**Vultr 的 Windows 机器默认开着 3389 端口（RDP），会被全世界的机器人暴力破解。**

**最安全的做法**：
1. 勾选 **Firewall** → 创建一个防火墙组
2. 规则：**只允许你的 IP 访问 3389**
3. 其他全部拒绝

**⚠️ 如果你暂时不想配防火墙，至少要做**：
- 部署后**立刻改掉 Administrator 密码**
- 或者先**只用一小时，测完就销毁**

---

## 第 8 步：给服务器起名 + 部署

1. **Hostname / Label**：起个名字，比如 `test-sg-win`
2. 确认右侧 Summary 的**价格是对的**
3. 点 **Deploy Now**

**⏱️ 等待时间**：Windows 机器初始化**比 Linux 慢**，通常 **5-15 分钟**（第三方提到 Windows 部署要 5-15 分钟，Linux 只要 1-2 分钟）。

# 二、⭐ 怎么连 RDP（连桌面）

## 第 9 步：拿到 IP 和密码

**部署完成后：**
1. 回到 **Products** → 点你刚建的服务器
2. 在 **Overview** 页面能看到：
   - **IP Address**（类似 `139.180.xxx.xxx`）
   - **Username**：`Administrator`
   - **Password** ⚠️ **点眼睛图标显示，明文只显示一次，马上复制保存！**

**⚠️ 密码如果没记下来** → 可以在这里 **Restart / Reset Password** 重置。

## 第 10 步：用电脑连

### 如果你用 Windows（你本机就是）

1. 按 **Win + R**，输入 **`mstsc`**，回车 → 打开「远程桌面连接」
2. **计算机**：粘贴刚才的 **IP**
3. 点 **连接**
4. 弹出登录框：
   - 用户名：`Administrator`
   - 密码：粘贴刚才保存的
5. ⚠️ 会弹「无法验证此远程计算机的身份」→ **点「是」**（正常现象）
6. **✅ 现在你看到 Windows 桌面了**

### 如果你用 macOS

下载 **Microsoft Remote Desktop**（App Store 免费），新建连接填 IP + 账号密码。

### 如果你用手机

iOS/Android 都有 **Microsoft Remote Desktop** App。

---

# 三、⚠️ 进桌面后必做的 3 件事

## ① 立刻改密码

**原因**：Vultr 默认密码格式固定，机器人和靠暴力破解的思路能猜到。

**方法**：桌面 → `Ctrl+Alt+End`（RDP 里的 Ctrl+Alt+Del）→ 改密码

## ② ⚠️ 检查能不能装你要的 AI 工具

**这是最关键的一步** —— 因为 **Windows Server ≠ Windows 11**：

| 能装 | 可能装不上 |
|---|---|
| Chrome / Edge | ⚠️ **微软商店的 App**（Server 没有商店） |
| Python / Node.js | ⚠️ 部分消费级 GPU 驱动软件 |
| VS Code / Git | ⚠️ 需要 Win11 特性（如 WSL2 的某些功能） |
| 大部分 CLI 工具 | |

**➡️ 建议**：先在机器上**试装你最需要的那个 AI 工具**，确认能装再继续用。**装不上就立刻销毁，别浪费钱。**

## ③ 拍个快照（如果打算长期用）

**Vultr 面板 → Snapshots → Take Snapshot**

**⚠️ 注意**：快照是**收费**的（按存储算）。只在你装好重要东西后拍一次。

---

# 四、⚠️⚠️ 测完怎么销毁（这步千万别忘）

**⚠️ Vultr 的「Stop」（关机）≠ 停止计费。** 只要机器还在，**照样按小时扣钱**。

## 销毁步骤

1. 进 **Products** → 点那台服务器
2. 点右上角 **⚙️ 设置图标** → 或滚到底部找 **Destroy**
3. **⚠️ 它可能让你输入服务器名字确认** → 输入后点 Destroy
4. 确认后**立刻停止计费**

**⚠️ 如果只是暂时不用**：
- 可以 **Stop**（省资源），**但账单继续** —— 除非你能接受
- **想真正不花钱 → 必须 Destroy**

# 六、⚠️ 可能会踩的坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| **看不到 Windows 图标** | 机房不支持 | 换 Tokyo 或换 Cloud Compute 类型 |
| **选了 Core 版进不去桌面** | Core 没有图形界面 | 销毁重开，选 Standard |
| **价格比预期贵** | 没算授权费 | 看右侧 Summary 最终价 |
| **连不上 RDP** | 机器还没初始化完 | 等 5-15 分钟，看状态是否 Running |
| **连上但很卡** | 配置太低 | 1核2G 只够测试，实用要 4核8G |
| **账单一直涨** | Stop 了但没 Destroy | 赶紧 Destroy |
| **装软件失败** | Windows Server 限制 | 正常，Server 不等于 Win11 |

# 七、⭐ 一句话总结

> **Vultr 新加坡开 Windows 机器是可以的，但记住三条：**
> **① 授权费额外算、且按配置跳档（1核2G 最划算，$26/月）**

**➡️ 建议：先开 1核2G 那台（$26/月，测 2 小时不到 1 块钱），确认能做你要的事，再决定要不要上 4核8G。**
