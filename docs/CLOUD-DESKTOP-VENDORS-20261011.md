## 一、先回答你最关心的那句话

> **「是否需要公司对接？」**
>
> **是。除了一个例外，全部都要公司。**

我把 10 家的渠道门槛全查了一遍，结论是：

**谷歌、微软、亚马逊、思杰（Citrix）、Omnissa、Nutanix —— 这些厂商的「转售渠道」全部要求：**
- 公司实体（营业执照 / 注册证书）
- 税号 / 税务登记
- 企业邮箱（不能是 Gmail）
- 通过 business verification（企业身份验证）

**个人身份进不去。这跟技术没关系，是渠道规则的硬门槛。**

**唯一的例外：Kasm Workspaces —— 它是软件，可以自己装在自己的服务器上，不需要任何人批准。**

### 🟢 3.1 Kasm Workspaces —— 不依赖资质，但**要付软件许可费**

**它是什么**：一套软件。你装在自己租的服务器上，它就变成一个「云桌面平台」，客户用浏览器就能进。

**为什么它跟别人不一样**：
别人是「租他的机器」，Kasm 是「买他的软件，机器是你的」。所以**没有任何渠道审批**——你不需要申请任何人。

| 项目 | 事实 |
|---|---|
| **社区版（Community）** | **免费，但明确只允许「自用 / 非营利 / 非商业」**，5 个并发会话 |
| **⚠️ 能不能商用** | ❌ **社区版禁止商业使用**（官方功能表：Commercial Use —— 社区版无） |
| **⚠️ 能不能白牌** | ❌ **社区版不行**，Custom Branding 是 Starter 起才有的功能 |

| **Enterprise** | 报价制（> 25 用户/会话时） |

**它的优势正好打中你的需求**：
- 客户「没有电脑」→ 手机浏览器也能打开
- 客户不懂技术 → 打开网址就能用
- 不依赖任何渠道资质

**它的弱点（必须知道）**：
- ⚠️ **社区版只能用来验证，不能用来卖给客户** —— 商业使用必须买 Starter

- **25 个客户 = $250/月许可 + 服务器费用**

**一句话**：**Kasm 省的是「资质」，不是「钱」。它让你绕开申请，但绕不开付费。**

### 🔵 3.2 AWS WorkSpaces —— 技术上最成熟，但要公司

**渠道计划**：AWS Partner Network（APN）

**申请要交什么**（官方要求）：政府签发的证件 + **公司名称** + **税务 ID** + **注册地区**

**⚠️ 2026 年的三个坑（这条最新）**：
1. **Simple AD 自 2026-07-30 起不再接受新客户** → 新的只能走 Managed Microsoft AD（**$86/月，且对 WorkSpaces 不免费**）或 AD Connector
2. **WorkSpaces Pools（多人共享一台，1000 人每人只要 $4.40 那个便宜方案）2026-07-31 起不再接受新客户** → 你现在申请也拿不到
3. PCoIP 协议 2027-10-31 停服 → 一律用 DCV

**也就是说**：AWS 那个「1000 人单价 $4.40」的诱人方案，**新客户已经用不了了**。之前文档里写的这个数字，对我们是无效的。

**客户凭据能否脱离**：✅ 能。给客户的是标准 DCV/RDP 账号密码，任何远程桌面软件都能连。

## 四、严格区分两件事：自用 vs 给客户用

这是**必须搞清楚**的一点，很多人在这里踩坑：

| 行为 | 能不能做 | 说明 |
|---|---|---|
| **我自己租一台云电脑，给我的客户演示** | ✅ 可以 | Shadow PC、Shells 都行，没人管你 |
| **我租一台，转手卖给客户当产品** | ❌ 不行 | 这需要转售授权，否则违反服务条款，账号会被封 |
| **我自己租服务器装 Kasm，卖给客户** | ✅ 可以 | 因为机器是你的，软件也是你买的 |

**「给我们的客户使用」的正确姿势**：
- 走**有正式渠道计划**的厂商（AWS APN / Microsoft CSP / Citrix CSP）→ 但要公司
- 或者**自己装软件在自己机器上**（Kasm）→ 不需要审批

**中间那条路（个人直接租再转卖）是不存在的。**

## 七、还有一个你必须知道的风险

**云电脑上会有客户的账号、密码、文件。**

虽然你技术上不主动去看，但**你持有这台机器的管理员权限**。

**如果做，必须做到**：
- 用户协议里写清：机器上的数据归谁、你能看到什么
- 提供「一键销毁」——客户随时能彻底删掉这台机器和数据
- ⚠️ **AWS 官方明确写着**：「Deleting a WorkSpace is a permanent action... data **does not persist and is destroyed**」
  → 删掉就是永久没了，**这条要在客户点删除前用大白话警告他**
- **绝不用管理员权限翻客户的东西**——这是信誉底线

**另外**：直接向客户收钱 + 机器在你账号下 = 在部分司法辖区可能被认定为**转售电信/云服务**，需要资质。这也是为什么正式渠道（有分销协议）比「自己开个账号硬转卖」安全。
