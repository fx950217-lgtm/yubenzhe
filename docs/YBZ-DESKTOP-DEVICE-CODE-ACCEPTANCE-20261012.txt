【三、机器码配对】
格式：YBZ-XXXX-XXXX，8 位字母/数字，排除 0/O、1/I；允许手机大小写、空格与分组输入。
电脑：POST /api/device-bridge/claim，action=create / rotate / poll。
手机：POST /api/social/devices/claim，原账号认证，输入 code 和可选 name。
电脑拿到独立的 32 字节高熵 pollSecret；短机器码不能领取长期设备 token。
只存短码哈希、轮询凭据哈希、设备 token 哈希；长期 token 由独立电脑秘密和设备 ID 的 HMAC 导出，响应丢失可在受限窗口重领，服务端无可恢复明文。
代码有效10分钟、用后清空哈希；重新生成立即废旧码。同 IP/账号每分钟最多5次，错误累积指数冷却；冷却中继续尝试仍计数。配对限流使用 socket IP，不信任请求伪造的 X-Forwarded-For。
最多5台设备；待配对记录1000、限流桶2048上限；容量满拒绝。
实际开发态 Electron 生成短码→真实本机390px浏览器输入→设备上线完成；安装版随后恢复相同加密配对状态。
脚本的真实 HTTP 验收使用隔离数据库与合成账号，没有冒充实体手机或远程云机。
实际命令：
  node scripts/verify-device-code.mjs --wait-expiry
结果：八类检查通过。实际等待600155ms；创建03:08:41.983Z、过期03:18:41.983Z、使用03:18:42.138Z，返回401 PAIR_EXPIRED。
