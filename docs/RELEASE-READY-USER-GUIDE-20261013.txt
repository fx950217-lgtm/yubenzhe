YBZ 愚笨者 0.14.0-dev.15 使用与反馈说明

下载安装：https://66.42.56.29/install.html
网页版：https://66.42.56.29/
Android 选择 APK；Windows 选择 x64 安装程序。Windows 当前没有代码签名证书，系统可能提示未知发布者，请核对来源与 SHA-256；不要关闭系统安全防护。尚未提交应用商店。

1. 创建自己的账号：设置 12–128 个字符的个人密码，系统随机分配 10 位 ID。记下 ID 和密码，手机与电脑可以登录同一个账号。本版不用邮箱验证码，不共享 reviewer 账号。
2. 在“我的→账号→安全”设置恢复方式并妥善保存。已有旧 ID＋6 位密码仍可登录；仍有有效会话的旧邮箱账号可主动初始化个人密码。没有有效会话且未绑定恢复方式的旧邮箱账号，不能自动恢复。
3. 连接自己的电脑：安装 Windows 客户端，打开“机器码与设备设置”，生成机器码；手机首次引导或“我的设备”输入机器码。代码仅给自己，过期后重新生成。手机生成配对文件的旧方式仍保留。
4. 设备页会显示屏幕、AI、文件等实际能力。AI 软件需要你自己安装并登录；平台不会代登录。选择可用 AI，在设备会话发送明确任务，遇到决策先核对再批准。
5. 钱包密钥只保存在本机，账号登录不会同步钱包。当前链上只允许测试网，勿转入主网资金。地址簿只存本机，选用地址后仍需核对网络和金额。

旧版本迁移：
Android 新包名 app.yubenzhe.mobile。旧 app.tongban.wallet.demo / app.tongban.wallet.localqa 可以与新包并存，原签名相同也不能自动迁移旧包的私有数据。先保留旧应用、确认离线钱包备份可恢复，在新应用恢复并核对地址后，再自行决定如何处理旧应用；不要先卸载。
Windows 应用标识 app.yubenzhe.desktop，旧 app.yubenzhe.desktop.preview。不要删除旧用户数据目录或钱包备份。

反馈请提供：设备型号/系统版本、App版本、进入哪个页面、操作步骤、提示文字与发生时间。不要发送账号密码、恢复码、助记词、私钥、完整密钥备份或远控凭据。
