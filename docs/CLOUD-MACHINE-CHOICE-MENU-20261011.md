## C-4 ⚠️⚠️ 这一页最重要：「解决区域 IP 限制」这件事，普通 VPS 做不到

**你的原话**：「解决区域注册 ip 限制，经商问题，在线多个问题」。

**我必须诚实告诉你**：

| 客户的需求 | 普通 VPS 能解决吗 |
|---|---|
| 「我要多个国家的电脑」 | ✅ **能**（搬瓦工切机房 / 多开几台） |
| 「我要多台机器同时在线」 | ✅ **能**（多开几台） |
| 「我要在中国用外网」 | ✅ **能**（CN2 GIA） |
| 「我要**注册需要当地身份的账号**」 | ❌ **不能** ⚠️ |
| 「我要**规避平台的地域风控**」 | ❌ **不能** ⚠️ |

**⚠️ 为什么不能：**

**「机房 IP」和「住宅 IP」是两个东西。**

- **机房 IP**（VPS 给你的）→ 所有平台都知道这是数据中心 → **很多国际平台（Google、Meta、银行、支付、电商）直接把机房 IP 拉黑**
- **住宅 IP**（真实的家庭宽带 IP）→ 平台认为是真人 → **才能过风控**

**➡️ 所以：**
- 客户说「我要开个美区账号」→ **普通 VPS 大概率开不了**，需要住宅代理
- 客户说「我要在海外有个电脑」→ **普通 VPS 完全够**

**⚠️ 这两个需求差很远，报价也不一样。别混着卖。**

**如果客户真的要住宅 IP** → 那是另一个产品线（住宅代理服务商，如 Bright Data / Oxylabs / IPRoyal），**价格贵 10-100 倍**。

## C-5 ⚠️ 红线页（这一页请务必看完）

**你的客户是「全世界」+ 用途是「解决区域 IP 限制」—— 这个组合天然靠近几个高风险场景：**

| 场景 | 风险 | 我们该怎么处理 |
|---|---|---|
| 批量注册账号（薅羊毛） | ⚠️ 违反平台条款，客户被封无赔偿 | **合同明确禁止**，不做这个承诺 |
| 规避金融实名（开海外银行/券商） | ⚠️ 可能触及帮信 | **绝对不碰** |
| 跨境诈骗 / 洗钱 | ⚠️ 刑事 | **绝对不碰 + 主动上报** |
| 无视听版权的内容分发 | ⚠️ 侵权 | **合同禁止** |
| 普通「我要个海外电脑办公」 | ✅ 正常 | 正常做 |

**⚠️ 根本原因**（延续上次的结论）：
- 机器是**我们的账户**开的 → 客户干什么**平台第一个找我们**
- 只要 1 个客户出事 → **可能牵连我们所有客户**

**➡️ 所以 C 段必须配一套「客户准入审查 + 用途申报 + 随时停机权」的流程，这不是可选项。**
