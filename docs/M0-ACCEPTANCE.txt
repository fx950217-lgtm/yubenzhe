浏览器完整流程（Chromium，390×844，localhost:18914）
- 两个模拟邮箱账号进入 → 虚拟 CTAP2 完成真实 WebAuthn UV 验证 → 确认恢复码。
- 字母/数字 ID 加好友并同意 → 操作者脚本确认 10.25 SIM-USD 入账 → 聊天发 1.25 SIM-USD 红包。
- 未创建钱包的收方领取后余额 1.25，发方余额 9.00；消息卡和独立红包记录由服务端关联。
- 上传真实 CSV → 估算/确认 → 三步实际处理 → 下载可读取 CSV；试用结算 0.03 USD，用户扣费为零。
- 本机导入随机测试私钥 → EIP-191 证明地址控制权 → 自动默认绑定。
- 有 2 SIM-USD 时删除钱包：服务端解绑、本机删除、最后确认完成；同一账号和 2 SIM-USD 保留。
- 中途已经清除本机钱包也可恢复完成确认；同地址重新导入后再删除，流程无须刷新完成。
- 修复了钱包密码弹窗的提交按钮、锁定事件打断删除完成确认、文件读取期间切换账号导致跨账号上传、任务接管取消后队列不释放等实际缺陷。
独立组件还验收了未绑定本机钱包删除、默认与本机地址不同的双重确认。通行密钥是虚拟验证器，不代表 Windows Hello 或手机实机已验收。
