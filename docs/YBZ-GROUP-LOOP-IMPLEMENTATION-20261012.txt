本轮最小场景的准确证据：
两个独立产品账号和真实HTTP会话 → 双账号群及实际群消息 → 明确标注的模拟模型方案 → 发起者批准 → 原文件工具真正CSV去重、生成可下载文件 → 成果哈希验收 → 消费者本机钱包实际签名 → 本地EVM挖出1笔chain97交易 → 3次确认 → 服务端核验回群 → 模拟链重组后撤销成功标记。
这证明代码联通，不等于真实AI服务＋公网测试网闭环已完成，也不是两名真人参加验收。

四、权限与安全实现

复用内部账号UUID、会话、好友关系、群成员/历史起点、禁言和版本机制。普通群成员能读取获分享成果，只有发起者能批准、验收、创建付款和登记哈希。新增成员/退群后重入者不能通过任务入口读取旧历史。
AI只接收明确的目标、工具计划及用户选择的文字片段，不读取个人AI聊天史或整个群史，不发送文件正文给模型。执行工具和输入由服务器限定，不将模型文案解释为任意命令。文件仍上传当前工作台服务真实处理。
批准绑定方案摘要、输入哈希、工具范围与积分预算，成果验收绑定输出哈希。旧工作台接口改变任务范围后，不得沿用原群批准付款。
POINT与tBNB分开；批准文件工具消耗测试积分，验收不付款。任务支付只支持BSC测试网97原生tBNB，最多1 tBNB；没有主网、托管账户、平台代签或自动付款。
密钥/助记词/密码不传AI或后端；广播前回调只有公开交易事实，不包括签名原文。每意图唯一哈希、哈希全局唯一。登记成功响应丢失、广播超时或状态不明均保留原哈希，只能核验，不能换哈希重签。
核验读取固定服务端配置的RPC，不接收用户RPC地址。严格校验from/to/value/data、签名链97、回执status、blockHash、规范区块及至少3次确认；旧格式交易从EIP-155的v推导链，拒绝无链保护签名。手续费取实际gasUsed×effectiveGasPrice，不捏造固定美元费。
未签付款可以取消，已有txHash不允许取消后重建付款。当前没有未知交易自动解锁或替换交易功能；需要后续人工诊断流程，不能以超时直接认定未付。
