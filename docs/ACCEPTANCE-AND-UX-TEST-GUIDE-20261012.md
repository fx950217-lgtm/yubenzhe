你问「有没有安卓端口」，**有，但现在不能用**。三个原因：

| # | 原因 | 说明 |
|---|---|---|
| 1 | **本机服务绑死 127.0.0.1** | 手机连不上电脑的这个地址 |
| 2 | **模拟邮箱只认本机 IP** | 手机来的请求会被判 403（`SIMULATION_LOCAL_ONLY`） |
