## 一、核心结论（先看这个）

| 您的问题 | 答案 |
|---|---|
| 一次性扣费还是按时长扣？ | ✅ **按小时扣**，用多久扣多久 |
| 停止（关机）能停止计费吗？ | ❌ **不能！关机照样扣钱** |
| 那怎么才能真正停止计费？ | ✅ **必须「销毁（Destroy）」实例** |
| 有月费上限吗？ | ✅ **有，封顶 672 小时/月**（=28 天） |
| 最小计费单位？ | **1 小时**（不足 1 小时按 1 小时算） |

> ⚠️ **这一条最关键**：您在控制台点「停止 / Stop」，**账单不会停**。
> 服务器只是「关机」，它的 CPU、内存、硬盘、IP 都还给您留着，所以继续收费。
> **只有「销毁（Destroy）」才停。销毁 = 数据全部删除，不可恢复。**

## 二、官方规则（✅ 已查实）

来源：`docs.vultr.com/support/platform/billing/how-am-i-billed-for-my-servers`

### 1. 计费方式

```
所有服务器均为【按小时计费】
  · 最小计费单位 = 1 小时
  · 从【部署那一刻】开始计费 —— 不管开机还是关机
  · 月度封顶 672 小时（普通云服务器）
  · GPU / VX1 机型封顶 730 小时
```

### 2. 关机也收费（官方原文）

> "Servers that are stopped but not destroyed continue to incur hourly charges
> for reserved resources such as compute, storage, and IP address allocations."
>
> 中文：停止但未销毁的服务器，会继续对已预留的计算、存储、IP 资源按小时计费。

**要停计费怎么办**：
> "To stop billing for a server, you must destroy it from your account.
> Stopping a server does not suspend billing."
>
> 中文：要停止计费，必须在账户里**销毁**它。停止操作不停止计费。

### 3. 672 小时封顶意味着什么

| 月份天数 | 实际小时 | 计费小时 | 说明 |
|---|---|---|---|
| 28 天（2月） | 672 | 672 | 正好封顶 |
| 30 天 | 720 | **672** | 白送 48 小时 🎁 |
| 31 天 | 744 | **672** | 白送 72 小时 🎁 |

**对您的好处**：一台机器**整月不停机**，收的就是那一个月费（$20 那档就是 $20）。
30 天的月份，相当于最后 2 天免费。

### 4. 自动备份额外收费（⚠️ 您现在正在为这个付钱）

> "An instance with automatic backups enabled will have a **20% higher** base
> monthly/hourly fee."

**备份 = 主机费用的 20%**。

## 五、关键：停计费的正确姿势

### ❌ 错误做法：点「Stop / 停止」

```
控制台 → 点停止 → 服务器显示 Stopped
结果：账单继续走 ⚠️
原因：CPU、内存、磁盘、IP 还在给您留着
```

### ✅ 正确做法：点「Destroy / 销毁」

```
API：  DELETE /v2/instances/{instance_id}
控制台：Server → Settings → Destroy Server
结果：计费立即停止
代价：数据全部删除，不可恢复
```

**销毁后计费怎么算**（实测验证过）：
- 按**已使用的小时数**结算，不足 1 小时按 1 小时
- 例：昨天 16:47 创建 → 17:35 销毁，用时 1 小时 → 计费 **1 小时 = $0.03**

### ⚠️ 三个「销毁也停不掉」的坑

| 坑 | 说明 |
|---|---|
| **快照/备份残留** | 单独的备份计划、快照存储会**继续按 GB 收费**，要一并删 |
| **保留 IP** | 预留 IP 单独收费，销毁服务器不会自动释放 |
| **块存储** | 挂载的独立磁盘独立计费，要单独销毁 |

## 六、给 ybz 定价的建议

### 6.1 成本基准（新加坡，2核4G）

| 配置 | 月成本 | 小时成本 | 适用 |
|---|---|---|---|
| Linux 2核4G | **$20** | $0.027 | 纯跑 AI 工具（够用） |
| Windows 2核4G | **$52** | $0.077 | 用户要图形界面 ⚠️ 贵 |
| Linux 2核4G + 备份 | $24 | $0.033 | 需要容灾 |
| Windows 2核4G + 备份 | $62.4 | $0.093 | 不建议 |

### 6.2 小时成本 → 定价公式

```
您的成本（2核4G Linux）= $0.027/小时
                        ≈ $0.65/天
                        ≈ $20/月

定价建议（按 3 倍毛利）：
  · 按小时卖：$0.08/小时 起
  · 按天卖  ：$2/天 起
  · 按月卖  ：$60/月 起
```

### 6.3 ⚠️ 三个定价陷阱（必须避开）

**陷阱 1：用户关机了，您还在付钱**

因为 Vultr **关机不停计费** —— 用户点「关机」以为不用付了，
但**账单照样在您身上累积**。

**对策**：
- 用户「关机」必须触发**您的后台自动销毁**（或至少立刻停掉用户侧的计费计时）
- 或者明确告知用户：**关机不等于省钱，要「释放」才停**

**陷阱 2：按小时卖但用户忘记关**

用户开了 1 小时以为关了，实际跑了 3 天 → 成本 $1.94，收入 $0.08。
**对策**：设**自动超时销毁**（比如闲置 2 小时自动释放）。

**陷阱 3：Windows 授权费吃掉利润**

Windows 比 Linux 贵 **$32/月**（+160%）。
如果给用户装 Windows 图形界面，定价必须单独加价，不能按 Linux 的价格卖。

### 6.4 我建议的产品形态

**优先做 Linux + 浏览器版**（不装图形桌面）：
```
成本：$20/月
用户视角：打开浏览器就能用，不需要"电脑桌面"
优势：便宜 60%、启动快、不用 RDP
```

**如果一定要图形界面**（用户要看"和电脑一样"）：
```
用 Linux + XFCE 轻量桌面  →  $20/月（成本不变！）
不要用 Windows           →  $52/月（贵 2.6 倍）
```
> 参考：Linux + XFCE + XRDP 这套我已经在真机上装通过（见 `RDP-DESKTOP-SG-20261012.md`），
> 成本与纯 Linux 相同，只是多花约 20 分钟安装。
