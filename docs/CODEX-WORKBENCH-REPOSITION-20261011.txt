## 背景：产品定位需要收敛

现在的「AI 工作台」定位太宽。它既想自己当 AI，又想管文件任务，又想管积分、赏金、服务商、趣味币。
结果是**用户看不出这个产品到底解决什么问题**。

我们要把定位收敛成一句话：

> **愚笨者的 AI 工作台，只解决一件事：帮不会折腾的人，把 AI 装好、把环境配好、把电脑连上。**
>
> **我们不做 AI。我们做「让 AI 用起来不费劲」这件事。**

具体来说，工作台的角色是**「AI 的安装管家和连接器」**，不是「另一个 AI 产品」：

- 用户想用 Codex / ChatGPT / Claude / DeepSeek / 本地模型 → **我们帮他装好、配好、连上**
- 用户没电脑 → **我们给他一台装好一切的云电脑**
- 用户不知道装哪个 → **我们问他 3 个问题，给他推荐**
- 用户的电脑和手机 → **我们让它们连起来**
- 装完之后 → **AI 用的是谁的账号、谁花钱，跟我们无关；我们只负责让它能跑起来**

### 二、设备页与云机页的定位对齐

文件：`tongban/src/personal-devices.js`、`workbench-hub.js`（devices / connections 两个 screen）

要求：
- 「我的设备」页的核心动作应该是：**连接我的电脑**（一个明显的主按钮）
- 「云端电脑」页的核心动作应该是：**开通一台云电脑**（未开通时）或 **打开我的云电脑**（已开通时）
- 两页都要有一句人话说明自己对应用户的哪种情况：
  ```
  我的设备页：「适合你已经有电脑的情况。」
  云端电脑页：「适合你还没有电脑，或者电脑不方便带着走的情况。」
  ```
  这样用户能自己判断该进哪个页面 —— **这是减少客服量的关键**。
