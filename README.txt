中文名：愚笨者；全球英文主名：YBZ。品牌主张：技能交给 AI，判断留给自己。英文：Let AI do the doing. You do the deciding. 三要素固定为：思维——知道要什么、为什么；决策——定方向、做取舍、担结果；创造性——把不相干的东西连起来。
五 Tab 固定顺序：工作台 → 消息 → 钱包 → 发现 → 我的；工作台为默认落地页和第一主任务。工作台首页呈现深色 Hero、品牌主张、积分卡、任务入口与近期动态；具体模板仍进入工作流广场查看，赏金、服务商、活跃榜、趣味币与积分归工作台。通讯录从消息进入。发现仅保留朋友圈、认识新朋友、收藏；我的仅保留账号、设置、云机、关于，个人资料与登录管理归账号，外观、安全、帮助和安装归设置，云机指向工作台设备页。 聊天为免费云端模型/本机模型两个入口。本机文字、链接收藏与历史草稿保留；旧 mine/points 和收藏返回来源兼容。最新 UI 要求覆盖需求全文旧页面结构，业务需求不变。
钱包卡下固定显示“密钥保存在你自己的设备上，平台不托管、不接触你的资金。”；积分卡下固定显示“积分不可转让、不可提现，仅可用于消耗站内服务。”。交易手续费优先使用链上回执实际数值，没有回执时明确标注预估或未提供；“手续费 $0.01”仅为明确标注的版式示例，不能作为真实交易固定报价。
