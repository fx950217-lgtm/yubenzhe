当前功能
默认进入 AI 工作台，底部顺序为工作台、消息、通讯录、发现、我。工作台首页只列入口，点击工作流广场后才显示模板；赏金论坛、服务商、活跃榜、趣味币发行与积分归工作台。聊天只留免费云端模型、本机模型两个入口。发现仅朋友圈、认识新朋友、收藏；我仅钱包、收藏、设置、帮助，账号、外观、安全和安装收进设置。积分从工作台进入，旧 mine/points 路由兼容。
本机文字/链接收藏可以实际保存，历史草稿保留，页面返回与刷新保留来源。当前导航按用户最新确认执行，覆盖技术需求全文中的旧页面结构；不改变目标与计划、POINT 预算、任务状态和真实文件成果等业务。通用模型、云电脑、多 AI 工作群、保险箱和分佣未接通时明确显示不可用。
消息、好友、群、朋友圈及账号资料由 /api/social 产品服务持久保存。消费者没有管理后台入口；朋友圈只从发现进入。个人资料 ID 与钱包独立，内部账号 UUID 不随公开 ID 修改。
POINT 页面显示可用/预留积分和服务流水；没有用户转赠、提现、换资产或 Gas 功能。旧平台余额、内部红包、资产榜及托管充提已移除。
钱包密钥仅在本机处理。支持 EVM 助记词（可选 passphrase 与派生路径）、私钥、V3 keystore 和只读地址导入，导入前核对地址。当前只连接 BSC 测试网；直接收款、签名转账与回执查询不经过平台托管。硬件直连、主网、跨链和链上红包仍未接通。
账号恢复码不是助记词，删除本机钱包不会注销产品账号、销毁链上地址或其他密钥副本。未知广播结果保留哈希并提示核查，不自动重发。

构建与测试
使用 Node 24、package.json 指定的 pnpm；从本目录执行：
  pnpm install --frozen-lockfile
  pnpm test
  pnpm build
完整产品能力须按运行手册启动 ../yubenzhe-deploy，不能只用静态服务代替后端。dist 通过 HTTP/HTTPS 提供，不用 file:// 打开模块。

资源与多端
app.js 中 theme-skins CSS 导入保持在其他 CSS 之后；新增颜色使用皮肤变量。简洁列表、系统字体、B 图标沿用现有设计，不通过删除业务提示掩盖不可用能力。
