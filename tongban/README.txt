0.11.0 功能与历史验收范围

当前消息和通讯录使用 /api/social 服务：6 位密码注册并随机分配数字 ID，个人资料修改昵称/头像/ID，账号设置更改密码。ID 为 6–16 位数字，服务端检查唯一性与保留号码。等级/官方认证不可自行编辑。好友申请、好友私聊、群创建/邀请/移除/转让/退出、文字/图片/表情均真实持久保存，独立账号之间通过轮询同步。没有推送通知、语音视频或端到端加密。
菜单严格为“扫一扫、添加好友、创建群聊”。添加好友仅输入数字 ID；扫码先查看资料再申请。
钱包独立于账号：支持 BIP39 助记词（可选 passphrase 和 EVM 派生路径）、EVM 私钥、V3 JSON keystore 导入，导入前展示地址并要求核对。只读地址观察不会获得签名能力。网络固定 BSC 测试网 97；不支持硬件直连签名、WalletConnect、主网、BTC/Solana/SLIP39。发现、榜单、平台余额、红包仍为本机体验；本次没有将这些内容迁入真实社交数据库。
客户端密钥只在本机处理和加密保存，不发送到账号服务。账号会话、好友关系及消息存在服务端 social-state；AI 和合成后台数据库分别保留。
运行完整账号/消息功能需要启动相邻 yubenzhe-deploy 服务，单独静态服务只能测试钱包和本地体验。

同伴 · BSC 钱包与熟人社交手机网页测试版
版本 0.6

产品方向
简约、明亮的手机界面；四个入口：消息、通讯录、发现、我的；资产收进“我的”。默认进入消息。
以好友关系为基础，支持好友和群文字聊天。排行榜按示例资产金额排序，陌生人只可申请加好友；没有语音、视频入口。

两类余额
1. 链上钱包：用户自行保管密钥。本版本固定 BSC 测试网 97，仅支持无价值的 tBNB；不提供主网切换。
2. 平台余额：计划由平台托管。发红包冻结平台余额，领取后进入领取者平台余额，24 小时未领部分退回发送者。充值、提现与链上钱包转账应独立核算。

已实现
- ethers 生成助记词钱包；备份词校验后才持久化密码加密的 JSON keystore。
- 助记词恢复、解锁、闲置/后台锁定、导出加密备份。
- 通过官方 BSC 测试网 RPC 读取余额、校验链 ID、估算费用、构建普通地址 BNB 转账、在本机签名和广播、查询回执。
- 确认时再次检查密码、余额、手续费、nonce；不确定广播状态保留本地哈希并提示核查，避免自动重发。
- 本机社交演示：好友申请、群创建、文字聊天、好友动态、示例资产榜。
- 本机零钱红包演示：普通/群拼手气红包、金额核对、领取状态、余额变化、到期退款。
- 独立服务端原型 server/custody-ledger.mjs：SQLite 事务、复式凭证、幂等、整数金额、并发领取、到期退款。尚未连接网页。

演示与真实功能边界
- 页面社交数据与零钱余额存于浏览器，仅用于体验。初始 1 tBNB 是虚构零钱，不是链上资产，不能充值、提现或兑换。
- 只有链上钱包模块会调用测试网；聊天消息不会发给真人，榜单不是实时排名。
- 只有用户主动确认才会签名和广播。开发验证没有广播任何真实网络交易；无需导入已有的真实资产钱包。
- 本地钱包与服务端账本测试通过不代表安全审计或正式资金托管已完成。
- 钱包目前不支持 BEP-20 代币、合约收款、跨链、主网或收款索引。交易列表只包括此浏览器发起的转账；以区块浏览器为准。
- JSON 密钥库以密码加密保存在此浏览器。浏览器数据丢失需要助记词恢复；浏览器被攻陷、XSS 或弱密码仍可能导致密钥泄露。真实资金上线前须独立审计与原生设备安全存储设计。

运行
Node.js >= 24；pnpm 11.19.0。
  pnpm install --frozen-lockfile
  pnpm build
  pnpm test
使用静态 HTTP/HTTPS 服务提供 dist 目录；不要用 file:// 打开模块脚本。
服务端账本只是未公开的库；没有 HTTP、登录、运营后台、充值或提现接口。参见 server/README.txt。

V0.2 产品变更
- 资产页区分链上钱包/平台余额，移除全部发红包入口；红包仅存在于好友和群聊。
- 转入/转出流程每次验证本机钱包密码。当前仅保存未提交草稿；无托管地址、扣款、充值入账或自动执行。
- 仅支持 BSC，其他网络一律不支持；当前链上模块仍只开放 BSC 测试网。
- 发现作为核心入口，包含朋友圈发布、点赞、评论、分享至熟人聊天；服务商、AI 工作台、赏金任务、排行榜、一键发币入口均有独立页面。
- 发现内所有资金结算规划走平台余额。当前服务申请、任务和发币仅保存本机草稿，不收费、不部署、不产生收益。
- 趣味 meme 发币服务费为 0 USDT；如产生网络费，上线后先披露再通过平台余额结算，当前不收取。代币默认存入指定 BSC 自托管钱包，不会自动出现在平台余额。
- 接入平台余额为独立申请，暂定 300 USDT（300U），当前只保存申请不扣费；不代表提供交易所上币、流动性、兑换或收益保证。复杂商业代币联系商务，当前可保存需求草稿，未发送给任何人。
- 不同币种单独记账，不自动兑换；USDT 余额目前为接入预览，tBNB 为本机演示额度。

V0.3 红包与聊天更新
- 好友普通红包；群拼手气、普通等额、专属红包。普通群红包按单个金额×个数计算，专属红包仅指定群成员可领。
- 红包发送需真实验证本机钱包密码，但只改变本机演示 tBNB 平台余额；无钱包时需用户先自行创建测试钱包。
- 聊天卡片不展示领取金额。先显示独立红包封面，用户点击“开”才触发演示领取；结果和详情展示领取名单、金额、时间及拼手气最佳。
- 每人限领一次，24小时退回未领余款。已经全部领取的红包到期后仍为已领完，不能显示已退款。
- 本机页面开启时检查到期，关闭页面后没有服务端定时退款；再次打开时补算。正式多人资金服务仍未接通。
- 好友和群聊支持本机图片、表情和原创大表情，图片先预览再保存至聊天。仅允许 JPG/PNG/WebP，最多3张、总计2MB，拒绝SVG及外链图片。
- 文件不上传，表情和图片不发送给真人。存储失败不显示发送成功；浏览器清理数据会移除本机聊天图片。
- 语音、视频仍未开放。

V0.4 平台体验优化

- 资产：平台余额显示尚未开通，不使用 0 USDT 冒充真实余额；本机演示额度独立卡片展示，无发红包入口。
- 账单中心：分开筛选本机链上转账、余额草稿、演示红包；详情可核对状态与地址，链上交易可刷新确认状态。不同币种与演示金额不合并。
- 发现：好友朋友圈优先，接续已有草稿，工作工具与探索分层；草稿编辑更新原记录；我的朋友圈支持只看自己。

- 钱包创建后可继续之前的收款、转账填写、转入或转出草稿流程。继续填写不会自动签名、转账、扣款或发送红包。
- 上述资料与演示内容仍在本机；刷新后已保存资料/草稿保留，聊天未发送输入仅在当前页面会话内保留。
