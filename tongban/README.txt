0.11.0 功能与历史验收范围

当前消息和通讯录使用 /api/social 服务：6 位密码注册并随机分配数字 ID，个人资料修改昵称/头像/ID，账号设置更改密码。ID 为 6–16 位数字，服务端检查唯一性与保留号码。等级/官方认证不可自行编辑。好友申请、好友私聊、群创建/邀请/移除/转让/退出、文字/图片/表情均真实持久保存，独立账号之间通过轮询同步。没有推送通知、语音视频或端到端加密。
菜单严格为“扫一扫、添加好友、创建群聊”。添加好友仅输入数字 ID；扫码先查看资料再申请。
钱包独立于账号：支持 BIP39 助记词（可选 passphrase 和 EVM 派生路径）、EVM 私钥、V3 JSON keystore 导入，导入前展示地址并要求核对。只读地址观察不会获得签名能力。网络固定 BSC 测试网 97；不支持硬件直连签名、WalletConnect、主网、BTC/Solana/SLIP39。发现、榜单、平台余额、红包仍为本机体验；本次没有将这些内容迁入真实社交数据库。
客户端密钥只在本机处理和加密保存，不发送到账号服务。账号会话、好友关系及消息存在服务端 social-state；AI 和合成后台数据库分别保留。
运行完整账号/消息功能需要启动相邻 yubenzhe-deploy 服务，单独静态服务只能测试钱包和本地体验。

同伴 · BSC 钱包与熟人社交手机网页测试版
版本 0.6

产品方向
简约、明亮的手机界面；四个入口：消息、通讯录、发现、我的；资产收进“我的”。默认进入消息。
以好友关系为基础，支持好友和群文字聊天。排行榜按示例资产金额排序，陌生人只可申请加好友；没有语音、视频入口。

两类余额
1. 链上钱包：用户自行保管密钥。本版本固定 BSC 测试网 97，仅支持无价值的 tBNB；不提供主网切换。
2. 平台余额：计划由平台托管。发红包冻结平台余额，领取后进入领取者平台余额，24 小时未领部分退回发送者。充值、提现与链上钱包转账应独立核算。

已实现
- ethers 生成助记词钱包；备份词校验后才持久化密码加密的 JSON keystore。
- 助记词恢复、解锁、闲置/后台锁定、导出加密备份。
- 通过官方 BSC 测试网 RPC 读取余额、校验链 ID、估算费用、构建普通地址 BNB 转账、在本机签名和广播、查询回执。
- 确认时再次检查密码、余额、手续费、nonce；不确定广播状态保留本地哈希并提示核查，避免自动重发。
- 本机社交演示：好友申请、群创建、文字聊天、好友动态、示例资产榜。
- 本机零钱红包演示：普通/群拼手气红包、金额核对、领取状态、余额变化、到期退款。
- 独立服务端原型 server/custody-ledger.mjs：SQLite 事务、复式凭证、幂等、整数金额、并发领取、到期退款。尚未连接网页。

演示与真实功能边界
- 页面社交数据与零钱余额存于浏览器，仅用于体验。初始 1 tBNB 是虚构零钱，不是链上资产，不能充值、提现或兑换。
- 只有链上钱包模块会调用测试网；聊天消息不会发给真人，榜单不是实时排名。
- 只有用户主动确认才会签名和广播。开发验证没有广播任何真实网络交易；无需导入已有的真实资产钱包。
- 本地钱包与服务端账本测试通过不代表安全审计或正式资金托管已完成。
- 钱包目前不支持 BEP-20 代币、合约收款、跨链、主网或收款索引。交易列表只包括此浏览器发起的转账；以区块浏览器为准。
- JSON 密钥库以密码加密保存在此浏览器。浏览器数据丢失需要助记词恢复；浏览器被攻陷、XSS 或弱密码仍可能导致密钥泄露。真实资金上线前须独立审计与原生设备安全存储设计。

运行
Node.js >= 24；pnpm 11.19.0。
  pnpm install --frozen-lockfile
  pnpm build
  pnpm test
使用静态 HTTP/HTTPS 服务提供 dist 目录；不要用 file:// 打开模块脚本。
服务端账本只是未公开的库；没有 HTTP、登录、运营后台、充值或提现接口。参见 server/README.txt。

- 朋友圈：好友/我的/收藏筛选与搜索；编辑自己的动态；好友可见/仅自己可见；归档与恢复；单图移除与大图浏览；自己的评论撤回与恢复。仅自己或已归档动态不能分享。
- 认证服务商：分类查看示例团队、服务详情和交付套餐，将意向套餐带入需求表单；所有目录项目标记示例/未认证，没有真实预约、评分或交易。
- AI 工作台：模板筛选、结构化目标/对象/语气/要求整理为可编辑提示词、复制和保存；这是本机模板工具，未调用模型或生成正文。
- 赏金：任务模板、验收标准、截止日期、计划人数与整数分配预算预览；只保存任务草稿，不发布、不冻结、不支付。
- 一键发币：基础信息→接收钱包→核对参数的三步准备；我的代币项目、参数复制/JSON导出；免费服务费0 USDT，当前无部署、无合约地址、无代币。
- 余额接入：独立300 USDT申请，已部署合约地址可选填并校验，未收费；支付不等于通过审核或拥有流动性，复杂商业需求可保存。
- 排行榜：按关系筛选、昵称搜索、金额排序、公开意向说明；仍为示例估值，不读取真实资产，不开放陌生人私聊。
- 草稿箱：搜索/分类、原位续编、复制新稿、JSON导出、可恢复归档；不伪装为订单，达到100份上限时拒绝新增而不静默删除旧稿。
- 发现内切换功能会保留当前编辑身份；未保存内容只在当前发现页面会话暂存，刷新或离开页面前请保存。检测到其他标签页先保存时拒绝旧页面覆盖，并提示先复制未保存内容再刷新。

V0.6 简洁导航与扫码
- 底部与桌面导航统一为消息、通讯录、发现、我的；我的资产从个人页进入。资产地址改为 #mine/assets，旧 #wallet 链接仍能打开。
- 我的首页突出资产入口，简化为资料、资产、朋友圈/草稿、账单、安全、帮助；不展示假余额，详细说明留在子页。
- 消息右上角 + 菜单提供扫码转账、添加好友、扫一扫，保留聊天和群入口。添加好友可在本机示例目录搜索，再显式发送本机申请；不能真实跨设备加好友。
- 扫码在本机处理：用户主动开启相机，也可选相册或手动输入。支持非零 EVM 地址、ethereum:address@97 收款码和 tongban://friend/id 本机好友码；拒绝其他明确网络、合约调用和未知链接。
- 识别后先展示结果。确认地址才进入原转账表单；金额由用户填写，仍需密码与交易详情确认，不会因扫码而广播。扫码不提供主网或代币转账。
- 相机在关闭、进入后台或识别后停止；图片与扫描内容不上传。网页相机仍取决于设备和浏览器授权，不支持时可用相册。
- 仅为扫一扫允许本站相机；麦克风和定位继续关闭。没有语音功能。
- 去掉重复口号与说明，保留关键网络、费用与未接通状态；切换资产账户不新增同页历史，账单历史保留各自来源。

主要文件
src/app.js、app-navigation.js 与 app.css/app-v6.css：四项导航、资产子页、钱包交互和响应式样式。
src/qr-scanner.js/css：本机相机/图片二维码识别、结果核对与资源释放。
src/wallet.js：自托管测试钱包与链上交易。
src/social.js 与 social.css：本机社交及红包体验。
src/redpacket-model.js：本机红包分配、权限、状态和过期退款。
src/chat-media.js 与 chat-media.css：图片校验及预览、表情面板与大表情。
src/discover.js 与 discover.css/discover-v5.css：发现入口、数据校验、排行榜和草稿箱。
src/discover-moments.js/css：朋友圈编辑、收藏、归档与图片浏览。
src/discover-workbench.js/css：示例服务目录、提示词工作台和赏金准备。
src/discover-token.js/css：分步代币准备、参数导出与余额接入申请。
src/profile-store.js 与 mine.js/mine.css：独立本机资料和个人中心。
src/bill-center.js 与 bill-center.css：分类账单和详情；不产生资金变动。
src/platform-transfers.js：密码验证后的未提交转入/转出草稿，不改变余额。
server/custody-ledger.mjs：服务端托管零钱账本原型。
tests/：离线钱包测试、账本事务测试及社交零钱测试。
.openai/hosting.json：私有 Sites 发布配置。
