打开应用

注册自己的账号

设置 12–128 个字符的个人密码，系统会分配账号 ID。请保存 ID，以后在手机和电脑上使用同一个 ID 与密码登录。

老账号仍可使用原 ID 和密码。账号密码与本机钱包密码分开，平台不会保存钱包密钥。

已有旧版的用户，请先确认钱包备份可恢复，保留备份后再进行应用迁移。更改安卓包名不能自动继承旧应用中的钱包与本机文件。

把自己的电脑连接到手机

  1. 在电脑安装 YBZ，打开设备连接向导。
  2. 电脑显示机器码后，在手机“我的设备”输入这组代码。
  3. 配对完成，在设备会话中发送任务，并确认执行。

设备仅本人可见。AI 软件的安装和登录由你本人完成。
